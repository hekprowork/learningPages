Lesson #0001 Chapter 1 Sedra & Smith Microelectronic Circuits

訊號、放大器模型與頻率響應精要

從微小感測訊號的等效電路出發，掌握電子學的核心支柱：受控源放大器模型、級聯負載效應與單時間常數 (STC) 頻率響應分析。

1. 訊號源模型與負載效應 (Signals & Transducers)

在真實物理世界中，資訊通常先由**轉換器 (Transducers)**（如麥克風、光電二極體、熱敏電阻）將非電氣物理量轉化為電氣訊號。任何線性訊號源皆可用兩種標準電路等效：

當訊號源接上負載電阻 $R_L$ 時，由於源端內阻 $R_s$ 的存在，實際跨在負載上的電壓為：

$$v_L = v_s \left( \frac{R_L}{R_s + R_L} \right)$$
負載分壓定理：欲使 $v_L \approx v_s$，必須滿足 $R_L \gg R_s$

2. 放大器的核心增益與功率關係

訊號經過放大器處理時，我們關注三種核心增益（Gain）以及訊號的線性度：

  • 電壓增益 (Voltage Gain)：$A_v \equiv \frac{v_o}{v_i}$，以分貝表示為 $20\log_{10}|A_v|\text{ dB}$。
  • 電流增益 (Current Gain)：$A_i \equiv \frac{i_o}{i_i}$，以分貝表示為 $20\log_{10}|A_i|\text{ dB}$。
  • 功率增益 (Power Gain)：$A_p \equiv \frac{P_L}{P_I} = \frac{v_o i_o}{v_i i_i} = A_v A_i$，以分貝表示為 $10\log_{10} A_p\text{ dB}$。

放大器輸出給負載的功率 $P_L$ 往往遠大於輸入訊號功率 $P_i$。多出來的能量並非憑空產生，而是由外部**直流電源供應器 (DC Power Supplies)** 提供：

$$P_{DC} = V_{CC} I_{CC} + V_{EE} I_{EE}$$ $$P_{DC} + P_i = P_L + P_{\text{dissipated}} \implies \text{效率 } \eta = \frac{P_L}{P_{DC}} \times 100\%$$
能量守恆：直流電能轉換為訊號功率與內部熱損耗功率

3. 四大基本放大器模型與二埠網路

根據輸入訊號與輸出受控源的類型，電子學將放大器抽象化為四種二埠 (Two-Port) 模型：

放大器類型 增益參數 開路/短路條件 理想輸入電阻 $R_i$ 理想輸出電阻 $R_o$
電壓放大器 (Voltage) $A_{vo} = v_o / v_i$ (V/V) 開路 ($i_o = 0$) $\infty$ (不抽訊號源電流) $0$ (負載變動不影響輸出電壓)
電流放大器 (Current) $A_{is} = i_o / i_i$ (A/A) 短路 ($v_o = 0$) $0$ (完全吸納訊號源電流) $\infty$ (負載變動不影響輸出電流)
轉導放大器 (Transconductance) $G_m = i_o / v_i$ (A/V) 短路 ($v_o = 0$) $\infty$ $\infty$
轉阻放大器 (Transresistance) $R_m = v_o / i_i$ (V/A) 開路 ($i_o = 0$) $0$ $0$
⚡ 互動實驗室：單級電壓放大器負載效應計算器

調整輸入阻抗與負載，即時觀察源端分壓損失、負載分壓損失與整體電壓增益 $G_v$：

實際輸入 $v_i$ 8.33 mV
負載輸出 $v_o$ 333.33 mV
負載電壓增益 $A_v$ 40.00 V/V
總體增益 $G_v (v_o/v_s)$ 33.33 V/V (30.46 dB)

4. 多級串接放大器分析 (Cascaded Amplifiers)

單一放大級往往難以同時達到高輸入電阻、高增益與低輸出電阻。工程實務上常將多級放大器**串接 (Cascade)**：

精選課本經典範例 (Example 1.3 深度拆解)

題目情境： 一個三級放大器連接訊號源（$v_s = 1\text{ mV}, R_s = 100\text{ k}\Omega$）與負載 $R_L = 100\ \Omega$。各級參數如下：

  • 第 1 級（電壓輸入級）：$R_{i1} = 1\text{ M}\Omega,\ A_{vo1} = 10\text{ V/V},\ R_{o1} = 1\text{ k}\Omega$
  • 第 2 級（中間增益級）：$R_{i2} = 10\text{ k}\Omega,\ A_{vo2} = 100\text{ V/V},\ R_{o2} = 1\text{ k}\Omega$
  • 第 3 級（功率輸出級）：$R_{i3} = 10\text{ k}\Omega,\ A_{vo3} = 1\text{ V/V},\ R_{o3} = 10\ \Omega$

計算步驟解析：

  1. 源端分壓： $v_{i1} = v_s \frac{R_{i1}}{R_s + R_{i1}} = 1\text{ mV} \times \frac{1000}{100 + 1000} = 0.909\text{ mV}$
  2. 第 1 級增益（以第 2 級 $R_{i2}$ 為負載）： $v_{i2} = A_{vo1} v_{i1} \frac{R_{i2}}{R_{o1} + R_{i2}} = 10 \times 0.909 \times \frac{10}{1 + 10} = 8.26\text{ mV} \implies A_{v1} = 9.09\text{ V/V}$
  3. 第 2 級增益（以第 3 級 $R_{i3}$ 為負載）： $v_{i3} = A_{vo2} v_{i2} \frac{R_{i3}}{R_{o2} + R_{i3}} = 100 \times 8.26 \times \frac{10}{1 + 10} = 751\text{ mV} \implies A_{v2} = 90.9\text{ V/V}$
  4. 第 3 級增益（以實際負載 $R_L$ 為負載）： $v_o = A_{vo3} v_{i3} \frac{R_L}{R_{o3} + R_L} = 1 \times 751 \times \frac{100}{10 + 100} = 683\text{ mV} \implies A_{v3} = 0.909\text{ V/V}$
  5. 總體電壓增益： $G_v = \frac{v_o}{v_s} = 0.909 \times 9.09 \times 90.9 \times 0.909 \approx 683\text{ V/V} = 56.7\text{ dB}$

5. 放大器頻率響應與單時間常數 (STC) 電路

由於電晶體內部存在寄生電容，外圍亦有耦合電容，放大器的增益是頻率 $\omega$ 的函數：$T(\omega) = |T(\omega)|e^{j\phi(\omega)}$。

電子學中大量的高頻衰減與低頻衰減電路皆可簡化為**單時間常數 (STC) 網路**：

低通 (Low-Pass) vs 高通 (High-Pass) STC 核心對比

$$T_{LP}(s) = \frac{K}{1 + s/\omega_0} \qquad T_{HP}(s) = \frac{K}{1 + \omega_0/s}$$

其中 3-dB 截止頻率 $\omega_0 = \frac{1}{\tau} = \frac{1}{RC}$。在 $\omega = \omega_0$ 處：

  • 增益振幅恰好下降至最大值的 $\frac{1}{\sqrt{2}}$（即下降 $3\text{ dB}$）。
  • 低通網路產生 $-45^\circ$ 相位落後；高通網路產生 $+45^\circ$ 相位超前。
  • 進入滾降區後，每經過 10 倍頻率（Decade），增益衰減 $20\text{ dB}$。

關鍵直覺 (Key Insight)

戴維寧與諾頓的工程選型：

當訊號源內阻極高時（如壓電感測器），視為電流源（諾頓）更為直觀；當內阻極低時（如電源穩壓器），視為電壓源（戴維寧）。

負載效應本質

電子學中最常見的錯誤是「忽略後級輸入電阻對前級的下拉效應」。計算多級增益時，必須由後往前依序求取實際等效負載。

分貝 (dB) 記憶法

電壓／電流比值（$20\log$）：

  • $\times 2 \approx +6\text{ dB}$
  • $\times 10 = +20\text{ dB}$
  • $\times 100 = +40\text{ dB}$
