# 建立積分因子法學習基線與核心架構

使用者已掌握一階常微分方程式基本分類（可分離、一階線性、正合），本次啟動專題學習：**積分因子法（非正合轉正合）**。本主題的核心在於理解 $\mu(x,y)$ 乘入原式後使 $\frac{\partial (\mu M)}{\partial y} = \frac{\partial (\mu N)}{\partial x}$ 的機制，並掌握單變數積分因子的判別與常見分組湊微分技巧。

## Implications
- 下一步需建立互動教學課程：深入拆解兩種單變數積分因子檢驗式與負號記憶法。
- 提供分步即時練習題，強化使用者在判別式分母選擇（除以 $N$ 還是除以 $M$）的決策速度。
