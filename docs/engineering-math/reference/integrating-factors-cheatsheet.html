一階 ODE 積分因子與正合法速查卡

標準微分形式：$M(x, y)\,dx + N(x, y)\,dy = 0$

一、 正合性判定 (Euler Test)

$$\text{若 } \frac{\partial M}{\partial y} = \frac{\partial N}{\partial x} \implies \text{正合 (Exact)} \implies \text{存在 } \phi(x,y) \text{ 使得 } d\phi = M\,dx + N\,dy = 0$$

二、 單變數積分因子速查表

型態 檢驗條件 / 判別式 積分因子 $\mu$ 公式
純 $x$ 函數 $\mu(x)$ $\frac{1}{N}\left(\frac{\partial M}{\partial y} - \frac{\partial N}{\partial x}\right) = f(x)$ $$\mu(x) = e^{\int f(x)\,dx}$$
純 $y$ 函數 $\mu(y)$ $\frac{1}{M}\left(\frac{\partial N}{\partial x} - \frac{\partial M}{\partial y}\right) = g(y)$ $$\mu(y) = e^{\int g(y)\,dy}$$
積函數 $\mu(xy)$ $\frac{\frac{\partial M}{\partial y} - \frac{\partial N}{\partial x}}{x N - y M} = h(u) \quad (u = xy)$ $$\mu(u) = e^{\int h(u)\,du}$$

三、 高頻常見微分分組 (湊微分速解表)

微分原形 展開式 常用積分因子 / 乘數
$d(xy)$ $x\,dy + y\,dx$ 無 (直接正合)
$d\left(\frac{y}{x}\right)$ $\frac{x\,dy - y\,dx}{x^2}$ 乘 $\frac{1}{x^2}$
$d\left(\frac{x}{y}\right)$ $\frac{y\,dx - x\,dy}{y^2}$ 乘 $\frac{1}{y^2}$
$d\left(\arctan\frac{y}{x}\right)$ $\frac{x\,dy - y\,dx}{x^2 + y^2}$ 乘 $\frac{1}{x^2 + y^2}$
$d\left(\frac{1}{2}\ln(x^2+y^2)\right)$ $\frac{x\,dx + y\,dy}{x^2 + y^2}$ 乘 $\frac{1}{x^2 + y^2}$
$d(\ln(xy))$ $\frac{dx}{x} + \frac{dy}{y} = \frac{y\,dx + x\,dy}{xy}$ 乘 $\frac{1}{xy}$

四、 待定係數型積分因子 $\mu = x^m y^n$

當方程式型如 $x^\alpha y^\beta (p y\,dx + q x\,dy) + x^\gamma y^\delta (r y\,dx + s x\,dy) = 0$ 時：

  1. 假設積分因子為 $\mu(x, y) = x^m y^n$。
  2. 全式乘上 $\mu$ 後令 $\frac{\partial (\mu M)}{\partial y} = \frac{\partial (\mu N)}{\partial x}$。
  3. 比較各項 $x$ 與 $y$ 的次方係數，聯立解出 $m$ 與 $n$。
