# 0008: 一階 ODE 工程應用：RL 與 RC 電路暫態分析

::: tip 🎯 單元學習目標
1. **電路微積分建模**：利用克希荷夫電壓定律（KVL）建立 RL 與 RC 網路的常微分方程式。
2. **暫態響應解析**：掌握零輸入響應（ZIR）、零狀態響應（ZSR）與完整響應的求解流程。
3. **時間常數與穩態準則**：深刻理解 $\tau = L/R$ 與 $\tau = RC$ 的物理意義、 $63.2\%$ 充飽電法則與 $5\tau$ 穩態準則。
4. **正弦穩態響應**：運用微分方程求解交流激勵下的穩態阻抗與相位角。
:::

---

## 一、 電路元件與 KVL 微分方程式建模

### 1. 核心元件微分關係
- **電阻 (Resistor, $R$)**：歐姆定律 $v_R(t) = R i(t)$
- **電感 (Inductor, $L$)**：電壓電流關係 $v_L(t) = L \frac{di}{dt}$
- **電容 (Capacitor, $C$)**：電流電壓關係 $i_C(t) = C \frac{dv_C}{dt}$ 或 $q(t) = C v_C(t)$

### 2. RL 串聯電路建模
考慮一個由電壓源 $E(t)$、電阻 $R$ 與電感 $L$ 組成的串聯迴路。根據**克希荷夫電壓定律 (KVL)**：
$$v_R(t) + v_L(t) = E(t) \implies R i(t) + L \frac{di}{dt} = E(t)$$
標準化為一階線性 ODE：
$$\frac{di}{dt} + \frac{R}{L} i = \frac{E(t)}{L}$$

### 3. RC 串聯電路建模
考慮電壓源 $E(t)$、電阻 $R$ 與電容 $C$ 串聯。根據 KVL：
$$v_R(t) + v_C(t) = E(t) \implies R i(t) + v_C(t) = E(t)$$
代入 $i(t) = C \frac{dv_C}{dt}$，得到以電容電壓 $v_C$ 為變數的一階線性 ODE：
$$RC \frac{dv_C}{dt} + v_C = E(t) \implies \frac{dv_C}{dt} + \frac{1}{RC} v_C = \frac{E(t)}{RC}$$

## 二、 暫態響應解析：齊次與非齊次解

### 1. 零輸入響應 (Zero-Input Response, ZIR) 與零狀態響應 (ZSR)
完整響應可拆解為兩部分：
- **零輸入響應 (齊次解 $i_h$)**：外加電源 $E(t) = 0$，僅由儲能元件的初始狀態（如初始電流 $i(0)$ 或初始電壓 $v_C(0)$）激發的響應。
- **零狀態響應 (特解 $i_p$)**：初始狀態為零，僅由外加激勵源 $E(t)$ 產生的響應。

### 2. 時間常數 ($\tau$) 與物理意涵
- **RL 電路**：時間常數 $\tau = \frac{L}{R}$。 $\tau$ 愈大，電流變化越緩慢（電磁慣性愈強）。
- **RC 電路**：時間常數 $\tau = RC$。 $\tau$ 愈大，充放電速率愈慢。
- **幾何與百分比準則**：
  - 當 $t = 1\tau$ 時，暫態響應衰減至初始差值的 $e^{-1} \approx 36.8\%$，或響應達到穩態值的 $1 - 0.368 = 63.2\%$。
  - **$5\tau$ 穩態準則**：當 $t = 5\tau$ 時，$e^{-5} \approx 0.0067$（小於 $1\%$），工程上認定系統已達到完全穩態（Steady State）。

## 三、 課本精選範例：直流階躍響應求解

**題目**：
一未充電的 RC 串聯電路中，$R = 10 \, \Omega$，$C = 0.1 \, \text{F}$。在 $t = 0$ 時接入一穩定直流電壓源 $E = 50 \, \text{V}$。試求電容電壓 $v_C(t)$ 的完整解析解，並計算當 $t = 0.5 \, \text{s}$ 時的電壓值。

**詳細解析**：
1. **建立微分方程式**：
   時間常數 $\tau = RC = 10 \times 0.1 = 1 \, \text{s}$。
   微分方程為：
   $$\frac{dv_C}{dt} + \frac{1}{1} v_C = \frac{50}{1} \implies \frac{dv_C}{dt} + v_C = 50$$
   初始條件：$v_C(0) = 0$。

2. **求解齊次解 (ZIR)**：
   對應齊次方程 $\frac{dv_h}{dt} + v_h = 0$，其特徵方程為 $r + 1 = 0 \implies r = -1$。
   齊次解為：
   $$v_h(t) = A e^{-t}$$

3. **求解特解 (ZSR)**：
   由於右側為常數 $50$，假設特解為常數 $v_p = K$：
   $$0 + K = 50 \implies K = 50$$
   故特解為 $v_p(t) = 50$。

4. **合成總響應並代入初始條件**：
   $$v_C(t) = v_h(t) + v_p(t) = A e^{-t} + 50$$
   代入初始條件 $v_C(0) = 0$：
   $$A e^{0} + 50 = 0 \implies A = -50$$
   因此，完整電容電壓響應為：
   $$v_C(t) = 50(1 - e^{-t})$$

5. **計算指定時間數值**：
   當 $t = 0.5 \, \text{s}$ 時：
   $$v_C(0.5) = 50(1 - e^{-0.5}) \approx 50(1 - 0.6065) = 50(0.3935) \approx 19.68 \, \text{V}$$
   當 $t = 5\tau = 5 \, \text{s}$ 時，電壓達到 $50(1 - e^{-5}) \approx 49.67 \, \text{V}$，趨近穩態 $50 \, \text{V}$。

## 四、 交流正弦激勵響應（穩態阻抗與相位）

### 1. 正弦激勵下的微分方程
若外加電壓為正弦波 $E(t) = V_m \cos(\omega t)$，以 RL 電路為例：
$$L \frac{di}{dt} + Ri = V_m \cos(\omega t)$$

### 2. 齊次解與特解假設
- **齊次解（暫態項）**：$i_h(t) = A e^{-\frac{R}{L}t}$，隨時間遞減趨近於零（稱為暫態消失）。
- **特解（穩態項）**：假設穩態電流形式為 $i_p(t) = I_m \cos(\omega t - \theta)$。
代入微分方程並利用相量法或三角恆等式，可解得振幅與相位：
$$I_m = \frac{V_m}{\sqrt{R^2 + (\omega L)^2}} = \frac{V_m}{|Z|}$$
$$\theta = \tan^{-1}\left(\frac{\omega L}{R}\right)$$
其中 $|Z| = \sqrt{R^2 + (\omega L)^2}$ 為電路的總阻抗大小。

---

::: warning 💡 考點防呆指南
1. **初始條件陷阱**：開關切換瞬間（$t = 0^-$ 到 $t = 0^+$），電感電流不能突變（$i_L(0^+) = i_L(0^-)$），電容電壓不能突變（$v_C(0^+) = v_C(0^-)$）。
2. **單位一致性**：計算時間常數 $\tau = RC$ 時，電阻單位為歐姆 ($\Omega$)、電容為法拉 ($\text{F}$)，相乘單位即為秒 ($\text{s}$)；若給微法拉 ($\mu\text{F}$) 必須正確換算成 $10^{-6} \, \text{F}$。
3. **暫態與穩態分離**：求解交流穩態時，切記齊次解代表暫態（隨時間消逝），工程應用中通常關注長久之後的穩態響應。
:::
