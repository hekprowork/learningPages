# 0003: 可分離變數方程式 (Separable Differential Equations)

## 🎯 單元學習目標
- 掌握一階常微分方程式中「可分離變數（Separable）」的判定條件。
- 熟練運用分離變數法（Separation of Variables）求解標準形式的常微分方程式。
- 理解並防範求解過程中的「失解（Singular Solutions）」與隱函數解的區間限制。
- 學會利用適當的變數代換（如 $u = ax + by + c$）將非分離型方程式化為可分離變數型態。

---

## 📋 核心數學定義

如果一階常微分方程式可以寫成函數 $g(y)$ 與 $f(x)$ 的乘積或商的形式，使得所有 $y$ 及其微分項與 $dx$ 歸為一側，所有 $x$ 歸為另一側，則稱為**可分離變數微分方程式**。

其標準微分形式為：
$$g(y) \, dy = f(x) \, dx$$

或等價的分離形式：
$$\frac{dy}{dx} = f(x) h(y)$$
其中 $h(y) = \frac{1}{g(y)}$。

---

## ⚙️ 解題 SOP 與理論推導

### 1. 求解標準演算法 (Step-by-Step)
1. **檢查與化簡**：將方程式整理成標準形式 $N(y) dy = M(x) dx$ 或 $\frac{dy}{dx} = f(x)g(y)$。
2. **尋找失解（常數解）**：令 $g(y) = 0$（或使分母為零的點），求出可能被消去而遺漏的特異解（Singular Solutions）。
3. **兩邊積分**：
   $$\int g(y) \, dy = \int f(x) \, dx + C$$
   其中 $C$ 為任意積分常數。
4. **化簡與求解**：執行積分計算，並嘗試將 $y$ 顯式解出（Explicit Solution），若無法顯式解出則保留隱函數形式（Implicit Solution）。
5. **代入初始條件 (IVP)**：若給定初始條件 $y(x_0) = y_0$，將其代入通解中求出特定的常數 $C$。

---

## 📖 課本精選範例

### 例題 1：基本分離變數與隱函數解
求解下列一階常微分方程式：
$$\frac{dy}{dx} = \frac{x^2}{1 - y^2}$$

#### 💡 解題詳解：
1. **分離變數**：
   $$(1 - y^2) \, dy = x^2 \, dx$$
2. **檢查失解**：
   此處無其他常數解使原方程式失效（分母 $1-y^2$ 在積分前已分離至左側）。
3. **兩邊積分**：
   $$\int (1 - y^2) \, dy = \int x^2 \, dx$$
   $$y - \frac{1}{3}y^3 = \frac{1}{3}x^3 + C_1$$
4. **整理通解**：
   同乘以 3 並移項：
   $$x^3 + y^3 - 3y = C \quad (\text{其中 } C = 3C_1)$$

---

### 例題 2：含初值條件 (IVP) 與失解檢驗
求解下列初值問題：
$$\frac{dy}{dx} = y \tan x, \quad y(0) = 2$$

#### 💡 解題詳解：
1. **尋找失解**：
   原式可寫為 $\frac{1}{y} dy = \tan x \, dx$。在分離變數時需將 $y$ 除至左側，這意味著我們假設了 $y \neq 0$。
   檢查 $y = 0$ 是否為解：若 $y = 0$，則 $\frac{dy}{dx} = 0$，且 $y \tan x = 0 \cdot \tan x = 0$，故 **$y = 0$ 是一個解**（此即為特異解 / 失解）。
2. **分離變數與積分**：
   $$\int \frac{1}{y} \, dy = \int \tan x \, dx$$
   $$\ln|y| = \ln|\sec x| + C_1$$
3. **化簡得通解**：
   $$\ln|y| - \ln|\sec x| = C_1 \implies \ln\left|\frac{y}{\sec x}\right| = C_1$$
   $$|y \cos x| = e^{C_1} \implies y \cos x = C \quad (\text{其中 } C = \pm e^{C_1} \text{ 或 } 0)$$
4. **代入初值條件**：
   代入 $x = 0, y = 2$：
   $$2 \cdot \cos(0) = C \implies C = 2$$
   故特解為：
   $$y \cos x = 2 \implies y = \frac{2}{\cos x} = 2 \sec x$$

---

### 例題 3：變數代換法 ($u = ax + by + c$)
求解微分方程式：
$$y' = (x + y + 1)^2$$

#### 💡 解題詳解：
1. **觀察與代換**：
   方程式右側為 $x+y+1$ 的函數，無法直接分離。令：
   $$u = x + y + 1$$
   則對 $x$ 微分得：
   $$\frac{du}{dx} = 1 + \frac{dy}{dx} \implies \frac{dy}{dx} = \frac{du}{dx} - 1$$
2. **代入原方程式**：
   $$\frac{du}{dx} - 1 = u^2 \implies \frac{du}{dx} = 1 + u^2$$
3. **分離變數**：
   $$\frac{1}{1 + u^2} \, du = dx$$
4. **兩邊積分**：
   $$\int \frac{1}{1 + u^2} \, du = \int 1 \, dx$$
   $$\arctan(u) = x + C$$
5. **還原變數**：
   因為 $u = x + y + 1$，代回得：
   $$\arctan(x + y + 1) = x + C$$
   取正切函數得顯式/半顯式解：
   $$x + y + 1 = \tan(x + C) \implies y = \tan(x + C) - x - 1$$

---

## ⚠️ 考點防呆指南

::: warning 🚨 必須防範的常見錯誤
1. **忽略常數解（失解）**：在將含有 $y$ 的因式除過去時（例如從 $g(y)y' = f(x)$ 化為 $y' = \frac{f(x)}{g(y)}$），務必先檢驗 $g(y) = 0$ 的根是否為原方程式的解。
2. **常數 $C$ 的擺放時機**：積分常數 $C$ 應在「完成不定積分的瞬間」立刻加上，而不是在最後才隨意補上，特別是在含有對數運算時（如 $\ln|y| = \ln|x| + C$，若寫成 $\ln|y| = \ln|x + C|$ 則是嚴重錯誤）。
3. **絕對值符號與定義域**：$\int \frac{1}{y} dy = \ln|y|$ 的絕對值在初始條件給定正負號時才能去絕對值，切勿過早省略。
:::
