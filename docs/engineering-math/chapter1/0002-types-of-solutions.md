## 1. 解的層次與分類

對於一個 $n$ 階微分方程，其解可從結構與包含常數的維度進行分類：

### 1.1 通解 (General Solution)
- 含有 $n$ 個相互獨立的任意常數（$C_1, C_2, \dots, C_n$）的 $n$ 階微分方程之解。
- 在幾何上，通解代表一族具有無限多條曲線的**積分曲線族**。

### 1.2 特解 (Particular Solution)
- 從通解出發，透過給定的附加條件（如初值條件或邊界條件）將任意常數具體定值後的解。
- 特解中不再含有任意常數。

### 1.3 奇異解 (Singular Solution)
- **定義**：不包含於通解之中（亦即無法透過對通解中的任意常數給予特定數值而得到），但它確實滿足該微分方程的解。
- **幾何意義**：奇異解通常是積分曲線族的**包絡線 (Envelope)**。在包絡線上的每一個點，無數條積分曲線與之相切，這往往導致該點處「解的唯一性失效」。

---

## 2. 初值問題 (Initial Value Problems, IVP)

一個常微分方程若伴隨一組在同一個自變數點處的附加條件，稱為**初值問題**。

例如對於一階 ODE：
$$\begin{cases}
\frac{dy}{dx} = f(x, y) \\
y(x_0) = y_0
\end{cases}$$

### 2.1 物理與幾何意義
- **幾何上**：在無數條積分曲線族中，初值條件 $y(x_0) = y_0$ 強制要求積分曲線必須**精確通過平面上的給定點 $(x_0, y_0)$**。
- **物理上**：若自變數 $t$ 代表時間，初值條件即為系統在初始時刻 $t_0$ 的狀態（如初始位置、初始速度），用以確定系統未來的唯一演化軌跡。

## 3. Picard-Lindelöf 存在唯一性定理

在求解微分方程前，我們必須先回答：「這個初值問題到底有沒有解？如果有，解是不是唯一的？」

### 3.1 定理敘述
考慮一階初值問題：
$$\frac{dy}{dx} = f(x, y), \quad y(x_0) = y_0$$
若函數 $f(x, y)$ 及其偏導數 $\frac{\partial f}{\partial y}$ 在包含點 $(x_0, y_0)$ 的某個開矩形區域 $R: |x - x_0| \le a, |y - y_0| \le b$ 內是**連續的**，則：
1. **存在性 (Existence)**：該初值問題在包含 $x_0$ 的某個鄰域內**至少存在一個解**。
2. **唯一性 (Uniqueness)**：該解是**唯一**的。

> [!IMPORTANT] 核心條件警示
> 須注意：連續性與偏導數連續僅為**充分條件**而非必要條件。即使不滿足偏導數連續，解仍可能存在或唯一；但若滿足該條件，則保證解的唯一性。

## 4. 經典範例與代入檢驗 SOP

### 範例 2.1：求解並利用初值條件定常數
求解初值問題：
$$\begin{cases}
y' = 2xy \\
y(0) = 3
\end{cases}$$

::: tip 詳解與推導
1. **分離變數求解通解**：
   $$\frac{1}{y} dy = 2x dx$$
   兩邊積分：
   $$\ln|y| = x^2 + C_1 \implies y = \pm e^{C_1} e^{x^2} = C e^{x^2}$$
2. **代入初值條件 $y(0) = 3$**：
   $$3 = C e^{0^2} \implies C = 3$$
3. **得出特解**：
   $$y = 3e^{x^2}$$
:::

---

### 範例 2.2：存在唯一性定理失效之反例
考慮初值問題：
$$\begin{cases}
y' = y^{1/3} \\
y(0) = 0
\end{cases}$$
試檢驗其解的個數。

::: tip 詳解與推導
1. **檢查函數與偏導數**：
   這裡 $f(x, y) = y^{1/3}$ 在 $y=0$ 處連續。
   但其偏導數 $\frac{\partial f}{\partial y} = \frac{1}{3y^{2/3}}$ 在 $y = 0$ 處**不連續（發散至無限大）**。因此 Picard 定理失效，唯一性不獲保證。
2. **尋找多重解**：
   - 明顯地，恆等函數 $y_1(x) = 0$ 是一個解。
   - 透過分離變數法求解：
     $$y^{-1/3} dy = dx \implies \frac{3}{2} y^{2/3} = x + C$$
     代入 $y(0) = 0 \implies C = 0$，得：
     $$\frac{3}{2} y^{2/3} = x \implies y = \left( \frac{2}{3}x \right)^{3/2} \quad (x \ge 0)$$
   - 因此，此初值問題同時存在兩個不同的解 $y_1(x) = 0$ 與 $y_2(x) = \left(\frac{2}{3}x\right)^{3/2}$，說明當偏導數不連續時，**唯一性會被破壞**。
:::

## 5. 考點防呆指南

> [!WARNING] 常見失分陷阱
> 1. **混淆通解與特解的常數**：在未代入初值前，算式中必須保留任意常數 $C$；代入後 $C$ 變成定值，切勿再當作通解處理。
> 2. **誤用唯一性定理**：當考試題目詢問「解是否存在或唯一」時，必須優先檢查 $f(x, y)$ 與 $\frac{\partial f}{\partial y}$ 在給定初值點的連續性，切勿直接盲目求解。
