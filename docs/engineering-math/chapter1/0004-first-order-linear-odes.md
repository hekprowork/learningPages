# 0004: 一階線性常微分方程式 (First-Order Linear Differential Equations)

## 🎯 單元學習目標
- 熟練一階線性常微分方程式的標準形式及其係數歸一化要求。
- 理解積分因子（Integrating Factor） $I(x) = e^{\int P(x)dx}$ 的第一原理推導與乘積法則還原。
- 掌握通解公式的套用與含初值條件（IVP）的特解求解。
- 熟悉 Bernoulli 方程式透過變數代換化為一階線性 ODE 的技巧。

---

## 📋 核心數學定義

一階線性常微分方程式的標準形式定義為：
$$y' + P(x)y = Q(x)$$

- **線性判定**：應變數 $y$ 及其導數 $y'$ 的次方皆為 1 次，且不相乘、不作超越函數運算（如 $\sin(y)$、$\ln(y)$）。
- **標準化要求**：首項 $y'$ 的係數必須嚴格為 1。若給定形式為 $a(x)y' + b(x)y = c(x)$，必須先同除以 $a(x)$ 才能正確辨識 $P(x)$ 與 $Q(x)$。

---

## ⚙️ 解題 SOP 與理論推導

### 1. 積分因子法 (Integrating Factor Method)

為了將左側化為可直接積分的形式，我們引入一個未知的乘數 $I(x)$（稱為積分因子），使等式左側變成一個完全微分（乘積法則的逆運算）。

將標準式同乘以 $I(x)$：
$$I(x)y' + I(x)P(x)y = I(x)Q(x)$$

我們希望左側等於 $[I(x)y]'^{\prime}$：
$$[I(x)y]' = I(x)y' + I'(x)y$$

對比係數可得微分方程式：
$$I'(x) = I(x)P(x) \implies \frac{I'(x)}{I(x)} = P(x)$$

兩邊積分：
$$\ln|I(x)| = \int P(x) \, dx \implies I(x) = e^{\int P(x) \, dx}$$
*(註：推導積分因子時通常取積分常數為 0)*

### 2. 通解公式推導
得到 $I(x)$ 後，原方程式可寫為：
$$[I(x)y]' = I(x)Q(x)$$

兩邊對 $x$ 積分：
$$I(x)y = \int I(x)Q(x) \, dx + C$$

最終得出**一階線性 ODE 通解標準公式**：
$$y(x) = \frac{1}{I(x)} \left[ \int I(x)Q(x) \, dx + C \right]$$

## 📖 課本精選範例

### 例題 1：標準積分因子法應用
求解下列一階線性微分方程式：
$$xy' + 2y = 4x^2$$

#### 💡 解題詳解：
1. **化為標準式**（首項係數歸一化）：
   同除以 $x$ （假設 $x \neq 0$）：
   $$y' + \frac{2}{x}y = 4x$$
   此時可辨識出 $P(x) = \frac{2}{x}$，$Q(x) = 4x$。
2. **計算積分因子 $I(x)$**：
   $$I(x) = e^{\int \frac{2}{x} \, dx} = e^{2\ln|x|} = e^{\ln(x^2)} = x^2$$
3. **套用通解公式**：
   $$y(x) = \frac{1}{x^2} \left[ \int x^2 \cdot (4x) \, dx + C \right]$$
   $$y(x) = \frac{1}{x^2} \left[ \int 4x^3 \, dx + C \right] = \frac{1}{x^2} [x^4 + C]$$
   $$y(x) = x^2 + \frac{C}{x^2}$$

---

### 例題 2：含初值問題 (IVP) 與指數積分
求解下列初值問題：
$$y' + 2xy = x, \quad y(0) = 0$$

#### 💡 解題詳解：
1. **確認已為標準式**：
   $P(x) = 2x$，$Q(x) = x$。
2. **計算積分因子**：
   $$I(x) = e^{\int 2x \, dx} = e^{x^2}$$
3. **建立乘積形式並積分**：
   $$(e^{x^2} y)' = x e^{x^2}$$
   兩邊積分：
   $$e^{x^2} y = \int x e^{x^2} \, dx$$
   利用代換積分法（令 $u = x^2, du = 2x dx$）：
   $$\int x e^{x^2} \, dx = \frac{1}{2} e^{x^2} + C$$
   故：
   $$e^{x^2} y = \frac{1}{2} e^{x^2} + C$$
4. **求解通解與特解**：
   $$y(x) = \frac{1}{2} + C e^{-x^2}$$
   代入初值 $x = 0, y = 0$：
   $$0 = \frac{1}{2} + C e^0 \implies C = -\frac{1}{2}$$
   特解為：
   $$y(x) = \frac{1}{2} (1 - e^{-x^2})$$

---

### 例題 3：伯努利方程式 (Bernoulli Equation) 轉換
求解非線性伯努利方程式：
$$y' + \frac{1}{x}y = x y^2$$

#### 💡 解題詳解：
1. **辨識與代換**：
   此為 $n = 2$ 的 Bernoulli 方程式。兩邊同除以 $y^2$：
   $$y^{-2}y' + \frac{1}{x}y^{-1} = x$$
   令代換變數 $u = y^{1-2} = y^{-1}$，則 $u' = -y^{-2}y'$，即 $-u' = y^{-2}y'$。
2. **代入化為線性 ODE**：
   $$-u' + \frac{1}{x}u = x \implies u' - \frac{1}{x}u = -x$$
3. **求解線性 ODE ($u$ 的方程式)**：
   $P(x) = -\frac{1}{x}$，$I(x) = e^{\int -\frac{1}{x} dx} = e^{-\ln x} = \frac{1}{x}$。
   $$\left(\frac{1}{x}u\right)' = \frac{1}{x}(-x) = -1$$
   兩邊積分：
   $$\frac{1}{x}u = -x + C \implies u = -x^2 + Cx$$
4. **還原變數 $y$**：
   因 $u = \frac{1}{y}$，故：
   $$\frac{1}{y} = -x^2 + Cx \implies y = \frac{1}{Cx - x^2}$$

## ⚠️ 考點防呆指南

::: warning 🚨 防錯口訣與常見陷阱
1. **首項係數歸一化（血淚教訓）**：千萬不能在 $a(x)y' + b(x)y = c(x)$ 時直接計算 $I(x) = e^{\int b(x)dx}$！務必先將 $a(x)$ 除掉，確保 $y'$ 係數為 1 才能算 $P(x)$。
2. **正負號防錯口訣**：
   - 積分因子指數內：「$P(x)$ 帶著正負號直接上積」。
   - 通解分母：「$I(x)$ 放分母，積分完記得乘 $\frac{1}{I(x)}$」。
3. **常數 $C$ 的位置**：積分常數 $C$ 必須包在括號內 $\int I(x)Q(x)dx + C$，再整體乘上 $\frac{1}{I(x)}$。若漏掉括號會導致 $C$ 沒有被積分因子正確除掉！
:::
