# 0001: 一階常微分方程基本概念與分類 (Basic Concepts & Classification of ODEs)

## 🎯 單元學習目標

1. **掌握基本定義**：清晰區分常微分方程（ODE）與偏微分方程（PDE），並能精準判定方程式的階數（Order）與次數（Degree）。
2. **線性與非線性判定**：熟練掌握一階及高階微分方程關於未知函數及其各階導數的線性檢驗法則。
3. **解的驗證與分類**：理解顯式解（Explicit Solution）、隱式解（Implicit Solution）、通解（General Solution）與特解（Particular Solution）的數學本質。
4. **幾何直觀連結**：理解方向場（Slope Fields / Direction Fields）與積分曲線族（Integral Curves）的幾何意義。

## 1. 核心數學定義

### 1.1 微分方程 (Differential Equations)
含有未知函數及其導數（或偏導數）的方程式稱為**微分方程**。根據未知函數所含自變數的個數，可分為兩大類：

- **常微分方程 (Ordinary Differential Equation, ODE)**：未知函數僅含**單一自變數**（例如 $x$ 或 $t$），方程式中僅出現常導數。
  $$\frac{dy}{dx} + P(x)y = Q(x)$$
- **偏微分方程 (Partial Differential Equation, PDE)**：未知函數含有**兩個或兩個以上自變數**，方程式中出現偏導數。
  $$\frac{\partial u}{\partial t} = c^2 \frac{\partial^2 u}{\partial x^2} \quad (\text{一維熱傳方程式})$$

### 1.2 階數與次數 (Order and Degree)
- **階數 (Order)**：微分方程中所出現的最高階導數的階數。
- **次數 (Degree)**：當微分方程經過有理化整理、使最高階導數的冪次為整數時，最高階導數項的冪次即為該方程式的次數。

> [!IMPORTANT] 核心判別原則
> 次數（Degree）的前提是**方程式必須能表示為未知函數及其導數的多項式形式**。若含有 $\sin(y'')$、$\ln(y')$ 等非多項式項，則該方程式的「次數」無定義。

## 2. 線性與非線性判定 (Linearity)

一個 $n$ 階常微分方程若能寫成如下標準線性形式，則稱為**線性常微分方程 (Linear ODE)**：

$$a_n(x) \frac{d^n y}{dx^n} + a_{n-1}(x) \frac{d^{n-1} y}{dx^{n-1}} + \dots + a_1(x) \frac{dy}{dx} + a_0(x) y = r(x)$$

### 2.3 嚴格檢驗三原則
1. **無次方相乘**：未知函數 $y$ 及其各階導數的分身不得相乘（例如 $y \cdot y'$ 或 $y' y''$ 均為非線性）。
2. **無超越函數複合**：$y$ 及其導數不得出現在三角函數、指數函數、對數函數等之內部（例如 $\sin(y)$、$\ln(y')$ 均為非線性）。
3. **係數僅為自變數函數**：各項的係數 $a_n(x), \dots, a_0(x)$ 僅能是自變數 $x$ 的函數（或常數），絕不能包含 $y$ 或其導數。

## 3. 解的型態與幾何直觀

### 3.1 顯式解與隱式解
- **顯式解 (Explicit Solution)**：形如 $y = \phi(x)$，未知函數已明確表達成自變數的函數。
- **隱式解 (Implicit Solution)**：形如 $G(x, y) = 0$，透過代數關係隱含地定義了 $y$ 與 $x$ 的函數關係。

### 3.2 幾何直觀：方向場與積分曲線族
對於一階 ODE：
$$\frac{dy}{dx} = f(x, y)$$
幾何上，函數 $f(x, y)$ 代表了在平面上任一點 $(x, y)$ 處切線的斜率。
- **方向場 (Direction Field / Slope Field)**：在網格點上繪製許多小短線段，其斜率為 $f(x, y)$，能全局展現所有解的流向。
- **積分曲線 (Integral Curve)**：滿足該微分方程的特定曲線。通解通常對應一族無限多的曲線（含有任意常數 $C$）。

## 4. 課本精選範例與詳細驗證

### 範例 1.1：階數與線性判定
判斷下列微分方程的階數、次數與線性性：
$$\left( \frac{d^3 y}{dx^3} \right)^2 + x \sin(y) = \frac{d y}{dx}$$

::: tip 詳解與推導
1. **最高階導數**：為 $\frac{d^3 y}{dx^3}$，故**階數為 3**。
2. **次數**：最高階導數的冪次為 $2$，故**次數為 2**。
3. **線性性**：由於出現了 $\sin(y)$（超越複合）以及最高階導數平方，因此判定為**非線性 (Nonlinear ODE)**。
:::

---

### 範例 1.2：驗證隱式解
驗證關係式 $x^2 + y^2 = C$ 是否為微分方程 $yy' + x = 0$ 的解。

::: tip 詳解與推導
1. 對隱式關係式兩邊關於 $x$ 微分（利用隱函數微分法）：
   $$\frac{d}{dx}(x^2 + y^2) = \frac{d}{dx}(C)$$
   $$2x + 2y \frac{dy}{dx} = 0$$
2. 化簡得：
   $$x + y y' = 0 \implies y y' + x = 0$$
3. 完美符合原微分方程，故 $x^2 + y^2 = C$ 為其一族通解（對應同心圓族）。
:::

---

### 範例 1.3：驗證帶有指數的通解
證明 $y = C_1 e^{2x} + C_2 e^{-3x}$ 是二階常微分方程 $y'' + y' - 6y = 0$ 的通解。

::: tip 詳解與推導
1. 計算一階與二階導數：
   $$y' = 2C_1 e^{2x} - 3C_2 e^{-3x}$$
   $$y'' = 4C_1 e^{2x} + 9C_2 e^{-3x}$$
2. 將 $y, y', y''$ 代入左式：
   $$\begin{aligned}
   LHS &= y'' + y' - 6y \\
   &= (4C_1 e^{2x} + 9C_2 e^{-3x}) + (2C_1 e^{2x} - 3C_2 e^{-3x}) - 6(C_1 e^{2x} + C_2 e^{-3x}) \\
   &= (4 + 2 - 6)C_1 e^{2x} + (9 - 3 - 6)C_2 e^{-3x} \\
   &= 0 \cdot C_1 e^{2x} + 0 \cdot C_2 e^{-3x} = 0 = RHS
   \end{aligned}$$
3. 驗證成立，且含有兩個獨立常數 $C_1, C_2$ 對應二階方程，故為通解。
:::

## 5. 考點防呆指南

> [!WARNING] 常見失分陷阱
> 1. **誤判非多項式為線性**：見到 $\ln(y)$ 或 $\cos(y')$ 絕對不可勾選線性。
> 2. **忽略有理化動作**：若方程式寫成 $\sqrt{y'} + x = 0$，必須先平方化為 $y' + x^2 = 0$ 才能正確判定其次數（此例中為 1 次）。
> 3. **通解常數個數不足**：$n$ 階線性 ODE 的通解必須包含 $n$ 個線性無關的任意常數，缺一不可。
