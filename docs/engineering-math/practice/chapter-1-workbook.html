Ex 1.1 可分離變數型方程式
Separable ODE

求解一階常微分方程式：

$$\frac{dy}{dx} = \frac{x^2}{1-y^2}$$
解題思路： 觀察式子右側可拆解為 $x$ 與 $y$ 的純分式乘積。交叉相乘將所有含 $y$ 項移至 $dy$ 側、含 $x$ 項移至 $dx$ 側，直接兩端積分。
步驟 1：交叉相乘分離變數
$$(1-y^2)\,dy = x^2\,dx$$
步驟 2：兩端直接積分
$$\int (1-y^2)\,dy = \int x^2\,dx \implies y - \frac{1}{3}y^3 = \frac{1}{3}x^3 + C'$$
步驟 3：整理移項與常數簡化
同乘 3 得：$$x^3 + y^3 - 3y = C$$（其中 $C = -3C'$）
Ex 1.2 齊次代換型方程式
Homogeneous ODE

求解微分方程式：

$$(x^2 + y^2)\,dx + 2xy\,dy = 0$$
解題思路： 檢驗各項次方皆為 2 次齊次式。令 $y = ux \implies dy = u\,dx + x\,du$，代入後消去 $x^2$ 化為可分離變數方程式。
步驟 1：變數代換
令 $y = ux$ 則 $dy = u\,dx + x\,du$。代入原式： $$(x^2 + u^2 x^2)\,dx + 2x(ux)(u\,dx + x\,du) = 0$$
步驟 2：提出 $x^2$ 並化簡
$$x^2\left[(1 + u^2)\,dx + 2u(u\,dx + x\,du)\right] = 0 \implies (1 + 3u^2)\,dx + 2ux\,du = 0$$
步驟 3：分離變數並積分
$$\frac{dx}{x} + \frac{2u}{1 + 3u^2}\,du = 0 \implies \ln|x| + \frac{1}{3}\ln(1 + 3u^2) = \ln|C_1| \implies x^3(1 + 3u^2) = C$$
步驟 4：代回 $u = \frac{y}{x}$
$$x^3\left(1 + 3\frac{y^2}{x^2}\right) = C \implies \mathbf{x^3 + 3xy^2 = C}$$
Ex 1.3 一階線性微分方程式
Linear ODE

求解一階線性微分方程式：

$$\frac{dy}{dx} + \frac{2}{x}y = x^3$$
解題思路： 標準一階線性型 $\frac{dy}{dx} + P(x)y = Q(x)$。先求積分因子 $I(x) = e^{\int P(x)\,dx}$，同乘後利用 $\frac{d}{dx}[I(x)y] = I(x)Q(x)$ 求解。
步驟 1：求積分因子
$$P(x) = \frac{2}{x} \implies I(x) = e^{\int \frac{2}{x}\,dx} = e^{2\ln|x|} = x^2$$
步驟 2：兩邊同乘 $x^2$ 並積分
$$x^2 \frac{dy}{dx} + 2xy = x^5 \implies \frac{d}{dx}(x^2 y) = x^5$$ $$x^2 y = \int x^5\,dx = \frac{1}{6}x^6 + C$$
步驟 3：求解 $y(x)$
$$\mathbf{y(x) = \frac{1}{6}x^4 + \frac{C}{x^2}}$$
Ex 1.4 白努利方程式 (Bernoulli ODE)
Bernoulli

求解非線性方程式：

$$\frac{dy}{dx} + \frac{1}{x}y = x y^2$$
解題思路： 此為 $y'=P(x)y+Q(x)y^n$ 型態（$n=2$）。兩邊同除以 $y^2$，令 $z = y^{1-n} = y^{-1}$ 降次轉化為線性 ODE。
步驟 1：同除以 $y^2$ 並做代換
$$y^{-2}\frac{dy}{dx} + \frac{1}{x}y^{-1} = x$$ 令 $z = y^{-1} \implies \frac{dz}{dx} = -y^{-2}\frac{dy}{dx}$，代入得： $$-\frac{dz}{dx} + \frac{1}{x}z = x \implies \frac{dz}{dx} - \frac{1}{x}z = -x$$
步驟 2：求 $z(x)$ 的積分因子與通解
$$I(x) = e^{\int -\frac{1}{x}\,dx} = \frac{1}{x} \implies \frac{d}{dx}\left(\frac{z}{x}\right) = \frac{1}{x}(-x) = -1$$ $$\frac{z}{x} = -x + C \implies z = -x^2 + Cx$$
步驟 3：代回 $y = z^{-1}$
$$\mathbf{y = \frac{1}{Cx - x^2}}$$
Ex 1.5 正合微分方程式
Exact ODE

求解方程式：

$$(2x + y)\,dx + (x + 3y^2)\,dy = 0$$
解題思路： 檢驗 $\frac{\partial M}{\partial y} = \frac{\partial N}{\partial x}$ 是否成立。成立即為正合，對 $M$ 積分求勢函數 $\phi(x,y)$。
步驟 1：正合性檢驗 (Euler Test)
$M = 2x + y \implies \frac{\partial M}{\partial y} = 1$
$N = x + 3y^2 \implies \frac{\partial N}{\partial x} = 1$
$\frac{\partial M}{\partial y} = \frac{\partial N}{\partial x} = 1$（確認為正合！）
步驟 2：積分求勢函數 $\phi(x,y)$
$$\phi(x,y) = \int (2x+y)\,dx = x^2 + xy + g(y)$$ $$\frac{\partial \phi}{\partial y} = x + g'(y) = x + 3y^2 \implies g'(y) = 3y^2 \implies g(y) = y^3$$
步驟 3：通解表示
$$\mathbf{x^2 + xy + y^3 = C}$$
Ex 1.6 非正合積分因子法
Integrating Factor

求解非正合方程式：

$$(2x^2 + y)\,dx + (x^2 y - x)\,dy = 0$$
解題思路： $M_y = 1$，$N_x = 2xy - 1$。測試判別式 $\frac{M_y - N_x}{N}$ 是否僅含 $x$，求出積分因子 $\mu(x) = e^{\int f(x)\,dx}$。
步驟 1：計算差值與判別式
$$M_y - N_x = 1 - (2xy - 1) = 2(1 - xy)$$ $$\frac{M_y - N_x}{N} = \frac{2(1 - xy)}{x(xy - 1)} = -\frac{2}{x} = f(x)$$
步驟 2：計算積分因子
$$\mu(x) = e^{\int -\frac{2}{x}\,dx} = e^{-2\ln|x|} = \frac{1}{x^2}$$
步驟 3：同乘 $\mu(x)$ 並積分
$$\left(2 + \frac{y}{x^2}\right)\,dx + \left(y - \frac{1}{x}\right)\,dy = 0$$ $$\phi(x,y) = \int \left(2 + \frac{y}{x^2}\right)\,dx = 2x - \frac{y}{x} + h(y)$$ $$\frac{\partial \phi}{\partial y} = -\frac{1}{x} + h'(y) = y - \frac{1}{x} \implies h'(y) = y \implies h(y) = \frac{1}{2}y^2$$ 通解：$$2x - \frac{y}{x} + \frac{1}{2}y^2 = C$$
Ex 1.7 分組湊微分法
Grouping Method

求解方程式：

$$(x + y)\,dx + (y - x)\,dy = 0$$
解題思路： 展開重新組合成 $(x\,dx + y\,dy) + (y\,dx - x\,dy) = 0$。觀察其對應 $\frac{1}{2}d(x^2+y^2)$ 與反三角全微分形態。
步驟 1：分組重構
$$(x\,dx + y\,dy) + (y\,dx - x\,dy) = 0$$
步驟 2：同除以 $x^2 + y^2$
$$\frac{x\,dx + y\,dy}{x^2 + y^2} + \frac{y\,dx - x\,dy}{x^2 + y^2} = 0$$ $$\frac{1}{2} \frac{d(x^2 + y^2)}{x^2 + y^2} - d\left(\arctan\frac{x}{y}\right) = 0$$
步驟 3：直接積分得解
$$\mathbf{\frac{1}{2}\ln(x^2 + y^2) - \arctan\left(\frac{x}{y}\right) = C}$$
Ex 1.8 工程電路應用（$RL$ 串聯電路）
Circuit Application

考慮一串聯 $RL$ 電路，電阻 $R = 10\ \Omega$，電感 $L = 2\ \text{H}$，外加直流電源 $E = 50\ \text{V}$。在 $t = 0$ 時開關閉合（初始電流 $i(0) = 0$）。求電路中的電流 $i(t)$。

解題思路： 根據克希荷夫電壓定律 (KVL)：$L\frac{di}{dt} + Ri = E(t)$。帶入數值建立一階線性微分方程，利用初始條件 $i(0)=0$ 求解特解。
步驟 1：建立微分方程式
$$2\frac{di}{dt} + 10i = 50 \implies \frac{di}{dt} + 5i = 25$$
步驟 2：求通解
積分因子 $I(t) = e^{\int 5 dt} = e^{5t}$
$$e^{5t}i = \int 25e^{5t}dt = 5e^{5t} + C \implies i(t) = 5 + C e^{-5t}$$
步驟 3：代入初值 $i(0) = 0$ 定出特解
$$0 = 5 + C \implies C = -5$$ $$\mathbf{i(t) = 5(1 - e^{-5t})\text{ A}}$$
