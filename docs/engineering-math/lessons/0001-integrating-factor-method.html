積分因子法：非正合轉正合的核心機制與實戰

當遇到無法分離變數、且非正合（$\frac{\partial M}{\partial y} \neq \frac{\partial N}{\partial x}$）的一階微分方程時，如何乘上神秘的「魔法乘數」$\mu(x,y)$，將死局化為全微分正合方程式？

一、 核心原理：積分因子是怎麼來的？

給定一階微分方程：

$$M(x, y)\,dx + N(x, y)\,dy = 0$$

若 $\frac{\partial M}{\partial y} \neq \frac{\partial N}{\partial x}$（非正合），我們希望找到一個非零函數 $\mu(x, y)$，兩邊同乘後滿足正合條件：

$$\frac{\partial (\mu M)}{\partial y} = \frac{\partial (\mu N)}{\partial x}$$

展開偏微分乘積法則：

$$\mu \frac{\partial M}{\partial y} + M \frac{\partial \mu}{\partial y} = \mu \frac{\partial N}{\partial x} + N \frac{\partial \mu}{\partial x} \quad\implies\quad \mu \left( \frac{\partial M}{\partial y} - \frac{\partial N}{\partial x} \right) = N \frac{\partial \mu}{\partial x} - M \frac{\partial \mu}{\partial y}$$

一般情況下解 $\mu(x,y)$ 屬於二元偏微分方程式（比原題目更難）。因此，工程數學中重點聚焦在單變數情況！

二、 兩大標準判別式與公式

1 情形一：$\mu$ 僅為 $x$ 的函數 $\mu(x)$

此時 $\frac{\partial \mu}{\partial y} = 0$，式子簡化為：

$$\frac{1}{N} \left( \frac{\partial M}{\partial y} - \frac{\partial N}{\partial x} \right) = f(x) \quad\implies\quad \mu(x) = e^{\int f(x)\,dx}$$
💡 記憶防呆口訣：分母是 $N$（右邊項），分子順序為「左偏減右偏」($M_y - N_x$)，消去後必須只剩 $x$！
2 情形二：$\mu$ 僅為 $y$ 的函數 $\mu(y)$

此時 $\frac{\partial \mu}{\partial x} = 0$，式子簡化為：

$$\frac{1}{M} \left( \frac{\partial N}{\partial x} - \frac{\partial M}{\partial y} \right) = g(y) \quad\implies\quad \mu(y) = e^{\int g(y)\,dy}$$
💡 記憶防呆口訣：分母換成 $M$（左邊項），分子順序反轉為「右偏減左偏」($N_x - M_y$)，消去後必須只剩 $y$！

三、 經典範例逐步拆解

例題：求解 $(3xy + y^2)\,dx + (x^2 + xy)\,dy = 0$

步驟 1：正合性檢驗

設 $M = 3xy + y^2$，$N = x^2 + xy$。

$\frac{\partial M}{\partial y} = 3x + 2y$，$\frac{\partial N}{\partial x} = 2x + y$。

因 $\frac{\partial M}{\partial y} \neq \frac{\partial N}{\partial x}$，方程式非正合！相減得：$M_y - N_x = (3x+2y) - (2x+y) = x + y$。

步驟 2：測試積分因子判別式

測試情形一（除以 $N$）：

$$\frac{M_y - N_x}{N} = \frac{x + y}{x^2 + xy} = \frac{x + y}{x(x + y)} = \frac{1}{x} = f(x)$$

剛好只剩下 $x$！求積分因子：

$$\mu(x) = e^{\int \frac{1}{x}\,dx} = e^{\ln|x|} = x$$
步驟 3：全式同乘 $\mu(x) = x$ 並求解勢函數

原式同乘 $x$ 得：

$$(3x^2 y + x y^2)\,dx + (x^3 + x^2 y)\,dy = 0$$

檢驗新正合性：$\frac{\partial}{\partial y}(3x^2y+xy^2) = 3x^2+2xy = \frac{\partial}{\partial x}(x^3+x^2y)$（正合！）。

對 $dx$ 項積分求勢函數 $\phi(x,y)$：

$$\phi(x, y) = \int (3x^2 y + x y^2)\,dx = x^3 y + \frac{1}{2}x^2 y^2 + h(y)$$

對 $y$ 偏微對照 $dy$ 項：$\frac{\partial \phi}{\partial y} = x^3 + x^2 y + h'(y) = x^3 + x^2 y \implies h'(y) = 0 \implies h(y) = C_1$。

最終通解：

$$x^3 y + \frac{1}{2} x^2 y^2 = C$$
