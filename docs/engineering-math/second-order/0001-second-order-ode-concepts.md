## 1. 核心定義與標準形式

### (1) 一般隱式形式
含有一元函數 \(y(x)\) 及其一階、二階導數的關係式，其一般隱式形式可寫為：
$$F(x, y, y', y'') = 0$$
其中 \(x\) 為獨立變數，\(y(x)\) 為應變數。若方程式能明確表示出最高階導數，則稱為顯式形式：
$$y'' = f(x, y, y')$$

### (2) 線性二階 ODE 一般形式
若未知函數 \(y\) 及其導數 \(y', y''\) 均為一次方，且不相乘、不作超越函數運算（如 \(\sin y, e^y\)），則稱為**線性二階常微分方程式 (Second-Order Linear ODE)**，其一般形式為：
$$R(x)y'' + P(x)y' + Q(x)y = S(x)$$

### (3) 標準型 (Standard Form)
在進行理論分析與求解時，通常將首項係數化為 \(1\)，得到**標準型**：
$$y'' + p(x)y' + q(x)y = f(x)$$
其中 \(p(x) = \frac{P(x)}{R(x)}\)、\(q(x) = \frac{Q(x)}{R(x)}\)、\(f(x) = \frac{S(x)}{R(x)}\)。
> **⚠️ 關鍵提醒**：將係數化為 1 是後續探討存在唯一性定理、Wronskian 行列式與變數變換的絕對前提。

### (4) 齊次與非齊次之定義
- **齊次 (Homogeneous)**：當標準型右側函數 \(f(x) \equiv 0\) 時：
  $$y'' + p(x)y' + q(x)y = 0$$
- **非齊次 (Nonhomogeneous)**：當標準型右側函數 \(f(x) \neq 0\) 時：
  $$y'' + p(x)y' + q(x)y = f(x)$$

## 2. 解的理論與初值問題存在唯一性定理

### (1) 二階 IVP 定義
一階 ODE 需要一個初始條件來決定常數，而二階 ODE 的通用通解包含兩個任意常數 \(c_1, c_2\)。因此，必須給定**兩個初始條件 (Initial Conditions, IC)** 才能完全決定特解：
$$\text{求解 } y'' + p(x)y' + q(x)y = f(x)$$
並滿足初始條件：
$$y(x_0) = K_0, \quad y'(x_0) = K_1$$
此即為**二階初值問題 (Initial Value Problem, IVP)**。

### (2) 存在與唯一性定理 (Existence and Uniqueness Theorem)
> **定理敘述**：
> 若函數 \(p(x)\)、\(q(x)\) 以及 \(f(x)\) 在包含點 \(x_0\) 的某開區間 \(I\) 上皆為**連續函數**，則存在**唯一**的函數 \(y(x)\)，它在該區間 \(I\) 上滿足二階線性 ODE，並同時滿足初始條件 \(y(x_0) = K_0, y'(x_0) = K_1\)。

### (3) 幾何與物理意涵
- **物理觀點**（以質點直線運動為例）：\(y(x)\) 代表位移，\(y'(x)\) 代表速度。給定初始位置 \(y(x_0) = K_0\) 與初始速度 \(y'(x_0) = K_1\)，在固定的外力定律（由微分方程式決定）下，質點的運動軌跡必然是唯一確定的。
- **幾何觀點**：在解曲線族中，存在唯一一條曲線通過指定座標 \((x_0, K_0)\) 且在該點具有指定的切線斜率 \(K_1\)。

## 3. 齊次方程之線性疊加原理 (Superposition Principle)

### (1) 定理內容
若 \(y_1(x)\) 與 \(y_2(x)\) 為齊次線性二階 ODE：
$$y'' + p(x)y' + q(x)y = 0$$
之兩個解，則其任意線性組合：
$$y(x) = c_1 y_1(x) + c_2 y_2(x)$$
（其中 \(c_1, c_2\) 為任意常數）亦為該齊次方程式之解。

### (2) 嚴謹代數代入驗證證明
將線性組合 \(y = c_1 y_1 + c_2 y_2\) 代入齊次微分方程式左側：
$$\begin{aligned}
L[y] &= y'' + p(x)y' + q(x)y \\
&= (c_1 y_1 + c_2 y_2)'' + p(x)(c_1 y_1 + c_2 y_2)' + q(x)(c_1 y_1 + c_2 y_2) \\
&= (c_1 y_1'' + c_2 y_2'') + p(x)(c_1 y_1' + c_2 y_2') + q(x)(c_1 y_1 + c_2 y_2) \\
&= c_1 \left( y_1'' + p(x)y_1' + q(x)y_1 \right) + c_2 \left( y_2'' + p(x)y_2' + q(x)y_2 \right)
\end{aligned}$$

因為 \(y_1\) 與 \(y_2\) 本身即為方程式之解，故括號內項皆為零：
$$\begin{aligned}
L[y] &= c_1 (0) + c_2 (0) = 0
\end{aligned}$$
這證明了 \(y = c_1 y_1 + c_2 y_2\) 確實滿足齊次方程式。 \(\blacksquare\)

### (3) 重要警示
> **⚠️ 疊加原理的邊界限制**：
> 1. **僅適用於齊次方程式**：若右側 \(f(x) \neq 0\)（非齊次），疊加原理不成立。
> 2. **僅適用於線性方程式**：對於非線性 ODE（例如含有 \((y'')^2\) 或 \(y y'\) 項），疊加原理完全失效。

## 4. 精選範例演練

### 範例 1：驗證三角函數解與線性組合
**題目**：試驗證 \(y_1 = \cos x\) 與 \(y_2 = \sin x\) 均為齊次線性 ODE \(y'' + y = 0\) 之解，並證明其線性組合 \(y = c_1\cos x + c_2\sin x\) 亦為其解。若給定初始條件 \(y(0) = 3\)、\(y'(0) = -2\)，求此初值問題的特解。

**解題步驟**：
1. **驗證 \(y_1 = \cos x\)**：
   $$\begin{aligned}
   y_1' &= -\sin x \\
   y_1'' &= -\cos x \\
   y_1'' + y_1 &= (-\cos x) + \cos x = 0 \quad (\text{滿足})
   \end{aligned}$$

2. **驗證 \(y_2 = \sin x\)**：
   $$\begin{aligned}
   y_2' &= \cos x \\
   y_2'' &= -\sin x \\
   y_2'' + y_2 &= (-\sin x) + \sin x = 0 \quad (\text{滿足})
   \end{aligned}$$

3. **根據疊加原理**：
   \(y = c_1\cos x + c_2\sin x\) 必為通解。

4. **代入初值條件求解 \(c_1, c_2\)**：
   - 由 \(y(0) = 3\)：
     $$c_1\cos(0) + c_2\sin(0) = 3 \implies c_1 = 3$$
   - 對 \(y(x)\) 微分求導：
     $$y'(x) = -c_1\sin x + c_2\cos x$$
   - 由 \(y'(0) = -2\)**：
     $$-3\sin(0) + c_2\cos(0) = -2 \implies c_2 = -2$$

5. **得出特解**：
   $$y(x) = 3\cos x - 2\sin x$$

## 5. 觀念思考與常見誤區

1. **忽略標準化直接套用係數**：
   若方程式給定為 \(x^2 y'' + x y' - 4y = 0\), 在 \(x = 0\) 處係數 \(R(x) = x^2 = 0\)，若直接除以 \(x^2\) 得到 \(p(x) = \frac{1}{x}\), 會發現 \(x=0\) 處不連續。初學者常忽略標準型轉換前的係數為零點，導致存在唯一性定理判斷錯誤。
2. **非線性方程誤用疊加原理**：
   對於非線性方程 \(y'' + y^2 = 0\), 若 \(y_1, y_2\) 為解, \(c_1 y_1 + c_2 y_2\) 代入後會產生交叉項 \((c_1 y_1 + c_2 y_2)^2 \neq c_1^2 y_1^2 + c_2^2 y_2^2\), 切勿盲目疊加。
3. **初始條件數量不足**：
   二階 ODE 的通解包含兩個獨立常數，若題目僅給定一個初始條件（如 \(y(0) = 1\)）, 將無法解出唯一特解，會留下一自由度。
