## 1. 降階法之核心思想與適用場景

在求解二階線性齊次常微分方程式（ODE）：
$$y'' + p(x)y' + q(x)y = 0$$

若我們已經透過觀察或其他方法找出了其中一個非零已知解 $y_1(x)$，我們希望能夠系統性地求得與其**線性獨立**的第二個解 $y_2(x)$，使得通解可以完整表示為：
$$y_h = c_1 y_1(x) + c_2 y_2(x)$$

### 為什麼叫「降階」？
降階法（Reduction of Order）的核心妙處在於：透過適當的變數代換，我們不需要直接解困難的二階方程式，而是將原本的二階 ODE 轉化為關於未知函數導數 $u'(x)$ 的**一階可分離變數 ODE**，從而降低問題的求解難度。

---

## 2. 嚴謹推導第一原理（Product Ansatz）

假設第二個解的形式為 $y_1(x)$ 與未知函數 $u(x)$ 的乘積（即 Product Ansatz）：
$$y_2(x) = u(x) y_1(x)$$

### 步驟一：計算一階與二階導數
$$y_2' = u' y_1 + u y_1'$$
$$y_2'' = u'' y_1 + 2u' y_1' + u y_1''$$

### 步驟二：代入原標準式
將 $y_2, y_2', y_2''$ 代入原標準式 $y'' + p(x)y' + q(x)y = 0$：
$$(u'' y_1 + 2u' y_1' + u y_1'') + p(x)(u' y_1 + u y_1') + q(x) u y_1 = 0$$

### 步驟三：重新分組
依 $u, u', u''$ 重新整理各項：
$$u \big[ y_1'' + p(x)y_1' + q(x)y_1 \big] + y_1 u'' + (2y_1' + p(x)y_1)u' = 0$$

### 步驟四：關鍵消去
因為 $y_1(x)$ 本身就是原齊次方程式的一個解，因此中括號內的項恆等於 0：
$$y_1'' + p(x)y_1' + q(x)y_1 = 0$$

方程式簡化為：
$$y_1 u'' + \big( 2y_1' + p(x)y_1 \big) u' = 0$$

### 步驟五：降階代換與求解
令 $v(x) \equiv u'(x)$，則 $v' = u''$，上式化為一階可分離變數 ODE：
$$y_1 v' + \big( 2y_1' + p(x)y_1 \big) v = 0$$

分離變數：
$$\frac{v'}{v} = -2\frac{y_1'}{y_1} - p(x)$$

兩邊對 $x$ 積分：
$$\ln|v| = -2\ln|y_1| - \int p(x)dx \implies v(x) = u'(x) = \frac{e^{-\int p(x)dx}}{y_1^2(x)}$$

再積分一次求出 $u(x)$：
$$u(x) = \int \frac{e^{-\int p(x)dx}}{y_1^2(x)} \, dx$$

因此，第二個獨立解 $y_2(x)$ 的通用公式為：
$$y_2(x) = y_1(x) \int \frac{e^{-\int p(x)dx}}{y_1^2(x)} \, dx$$

### Wronskian 獨立性驗證
透過 Wronskian 行列式檢驗 $y_1$ 與 $y_2$ 的線性獨立性：
$$W(y_1, y_2) = y_1 y_2' - y_1' y_2 = y_1^2 u' = e^{-\int p(x)dx} \neq 0$$
由於指數函數恆不為零，保證了 $y_2$ 與 $y_1$ 必線性獨立！

## 3. 課本範例詳細手算演練

### 範例 1：常係數重根由來（對應課本 P14）
**題目**：已知 $y_1(x) = e^{-2x}$ 是 $y'' + 4y' + 4y = 0$ 之一解，求第二個線性獨立解 $y_2(x)$。

**演練過程**：
1. 標準式中 $p(x) = 4$。
2. 代入降階公式：
   $$u(x) = \int \frac{e^{-\int 4 \, dx}}{(e^{-2x})^2} \, dx = \int \frac{e^{-4x}}{e^{-4x}} \, dx = \int 1 \, dx = x$$
3. 得到第二解：
   $$y_2(x) = u(x)y_1(x) = x e^{-2x}$$
4. **Wronskian 驗證**：
   $$W(e^{-2x}, xe^{-2x}) = \begin{vmatrix} e^{-2x} & xe^{-2x} \\ -2e^{-2x} & (1-2x)e^{-2x} \end{vmatrix} = e^{-4} \neq 0$$
5. **結論**：此即常係數二階 ODE 發生特徵方程式重根時，必須乘上 $x$ 的嚴密理論來源。

---

### 範例 2：變係數 ODE 求解（對應課本 P14-P15）
**題目**：求解變係數微分方程式 $x^2 y'' - 3x y' + 4y = 0 \quad (x > 0)$，已知一解為 $y_1(x) = x^2$。

**演練過程**：
1. 將方程式化為標準式（同除以 $x^2$）：
   $$y'' - \frac{3}{x}y' + \frac{4}{x^2}y = 0 \quad \implies p(x) = -\frac{3}{x}$$
2. 計算積分因子部分：
   $$\int p(x)dx = \int -\frac{3}{x} dx = -3\ln x = \ln(x^{-3})$$
   $$e^{-\int p(x)dx} = e^{-\ln(x^{-3})} = x^3$$
3. 代入 $u(x)$ 公式：
   $$u(x) = \int \frac{x^3}{(x^2)^2} \, dx = \int \frac{x^3}{x^4} \, dx = \int \frac{1}{x} dx = \ln x$$
4. 得到第二個解：
   $$y_2(x) = y_1(x) u(x) = x^2 \ln x$$
5. **Wronskian 驗證**：
   $$W(x^2, x^2\ln x) = \begin{vmatrix} x^2 & x^2\ln x \\ 2x & 2x\ln x + x \end{vmatrix} = x^3 \neq 0 \quad (\text{for } x > 0)$$
6. **齊次通解**：
   $$y(x) = c_1 x^2 + c_2 x^2 \ln x$$

## 4. 解題 SOP 總結與記憶口訣

### 解題口訣
> **「一設二導三代入，降階代換求積分」**

### 實用操作指南（假設法 vs 公式法）
1. **假設法（First Principles）**：
   - 考試或推導時推薦使用 `y_2 = u(x)y_1` 直接代入原方程式。
   - 展開後利用 $y_1$ 為解的條件將 $u$ 項消去，令 $v = u'$ 降階為一階 ODE 求解。
2. **公式法（Quick Formula）**：
   - 若熟練公式，可直接記憶並代入：
     $$y_2(x) = y_1(x) \int \frac{e^{-\int p(x)dx}}{y_1^2(x)} \, dx$$
   - 注意使用公式前必須先將方程式化為**首項係數為 1 的標準式**以正確識別 $p(x)$。
