# 給我的 Agent 出模考

填寫需求，複製 Prompt，再貼給你自己的 AI agent。Agent 會讀取公開題庫、核對原題，回傳一個跨章、跨科的模擬考連結。

<AgentExamPrompt />

你的 agent 需要能讀取公開網址。Prompt 不會自動傳送給任何 AI 服務；請自行貼上使用。
