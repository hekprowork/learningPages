# 對話模型讀取相容性

網站能以 HTTP 200 回應，不代表每個模型的網頁工具都允許讀取。模型沒有連網能力，或工具禁止整個網域時，改副檔名、換成 HTML 也無法保證可讀；請使用[免連網出題](/agent-exam#offline-mode)。

| 流程 | 格式與限制 | 提供的方式 |
| --- | --- | --- |
| 操作指引 | TXT 與 HTML；仍需要模型獲准讀網址 | 連網 Prompt 內也寫入入口與失敗處理 |
| 題目索引 | UTF-8 TSV、7 欄；只含定位資訊，不含題幹 | HTML 章節目錄可直接選題；免連網時由使用者瀏覽器讀取目錄資料 |
| JSON／雜湊 | 某些工具不支援；一般選題不需要 | 保持可選；版本也有 HTML、TXT |
| 原題 | 單題靜態 HTML，不依賴 JavaScript；公式 SVG 不一定能完整轉成文字 | 每題另提供保留原始 LaTeX 的 TXT |
| 圖片 | 純文字模型或禁止下載圖片的工具不能直接看圖 | 候選題列印成 PDF 上傳；不支援圖像時勾選「只選無圖題」 |
| 詳解 | 與題幹分開，避免初次出題洩漏答案與增加文字量 | 按需讀取獨立詳解頁；免連網候選集預設只附題幹 |
| 組卷 | `exam.html?ids=...` 的實際題卡需要 JavaScript | 模型可從已提供的 ID 組連結，無法執行畫面驗證時須明說 |
| 無連網能力 | 提供 URL 不會讓模型自動取得內容 | 複製含完整原題的 Prompt；圖像題同時附候選題 PDF |

免連網模式每批模考 1–10 題，最多準備 20 題候選，模型再依需求選題。超過文字容量時明確要求分批，不截斷題目。準備題目仍需要使用者的瀏覽器能連到本站。

原始題幹、數值、LaTeX 與教材來源沿用題庫；格式與索引檢查不等於已證明每一道答案正確。任何模式若缺少必要圖表，都應回報缺漏，不能猜測電路或編造條件。

本次曾測得：一般 HTTP 請求可讀，但測試用網頁讀取工具拒絕本站 HTML、TXT、TSV，連首頁也不可存取。因此工具權限問題須與檔案格式問題分開判斷，不能宣稱對所有模型皆可讀。
