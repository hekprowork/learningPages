# 對話模型讀取相容性

網站能以 HTTP 200 回應，不代表每個模型的網頁工具都允許讀取。持續型 AI 可先把[完整題庫資料包](/agent-context.txt)附加到專案或 Agent 指示，之後直接在該 Agent 對話貼錯題；不用每題回網站填表。單次對話或需要限制範圍時，再用[相似練習表單](/agent-exam)生成 Prompt。若 AI 無法連網，還需附上對應離線章節檔與必要原題圖表；資料包只含流程和 metadata，不含題幹、圖片。舊網址 `#offline-mode` 仍可開啟次要模考工具。

| 流程 | 格式與限制 | 提供的方式 |
| --- | --- | --- |
| 相似題搜尋 | 預設跨四科、17 章與所有題型搜尋 | 一次性資料包含完整 workflow 和全題庫 metadata；持續型 Agent 加入一次後，可直接收錯題 |
| 單次聊天 | Prompt 仍需要 Agent 獲准讀取資料包網址 | 表單生成的 Prompt 指向單一 context pack，Example／Exercise 是軟性偏好 |
| 操作指引 | TXT 與 HTML；仍需要模型獲准讀網址 | 資料包合併操作流程、題庫索引、存取限制和失敗處理 |
| 題目索引 | UTF-8 TSV、7 欄；只含定位資訊，不含題幹 | HTML 章節目錄可直接選題；免連網時由使用者瀏覽器讀取目錄資料 |
| JSON／雜湊 | 某些工具不支援；一般選題不需要 | 保持可選；版本也有 HTML、TXT |
| 原題 | 單題靜態 HTML，不依賴 JavaScript；公式 SVG 不一定能完整轉成文字 | 每題另提供保留原始 LaTeX 的 TXT |
| 圖片 | 純文字模型或禁止下載圖片的工具不能直接看圖 | 提供題圖或離線章節檔；看不到必要圖表時要說明限制 |
| 詳解 | 與題幹分開，避免相似練習初次洩漏答案 | 等學習者要求解答或再次嘗試後才提供完整解法 |
| 組卷 | `exam.html?ids=...` 的實際題卡需要 JavaScript；模型介面可能改寫可點擊網址 | 要求以程式碼區塊輸出網址；可把選定 ID 貼回網站核對範圍、題數、重複與順序，由網站產生直接連結。未執行畫面驗證時須明說 |
| 無連網能力 | context pack 不含原題全文與圖片，不能單獨完成候選核對 | 附上相關離線章節檔、錯題原題與必要圖表；若需搜尋全部科目，須提供完整離線題目資料 |

搜尋範圍預設完整，不要求學習者先判斷題目科目或章節。只有明確啟用科目／章節限制或題型限制才縮小搜尋；打開設定或修改內容本身不會生效。題型限制啟用時預選 Example 與 Exercise。Prompt 生成不逐題抓取網路，也不抽樣或截斷索引；手動限制下零題仍會產生 Prompt。種子題在 inventory 中保留，只從推薦候選排除。作答步驟選填；未提供時不應推測錯因。原模考工具保留在頁面次要區塊。

原始題幹、數值、LaTeX 與教材來源沿用題庫；格式與索引檢查不等於已證明每一道答案正確。任何模式若缺少必要圖表，都應回報缺漏，不能猜測電路或編造條件。

本次曾測得：一般 HTTP 請求可讀，但測試用網頁讀取工具拒絕本站 HTML、TXT、TSV，連首頁也不可存取。因此工具權限問題須與檔案格式問題分開判斷，不能宣稱對所有模型皆可讀。
