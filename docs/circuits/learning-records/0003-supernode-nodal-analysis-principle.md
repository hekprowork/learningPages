# 0003: 超節點分析法的物理包絡原理與拘束方程式架構

> 剖析浮動電壓源之未知支路電流困境、封閉面高斯包絡與方程式維度不變性

##  學習紀錄核心重點

本單元建立處理含有「浮動電壓源（跨接於兩非參考節點之間）」之節點分析法第一原理框架。透過將電壓源及其並聯元件包絡為廣義封閉高斯面（超節點），成功避開電壓源內部未知電流 $i_v$ 無法用歐姆定律表達的致命困難，並結合電壓源兩端電位差之「拘束方程式（Constraint Equation）」，建構完整的 $N$ 元一次聯立方程組解題體系。

---

## 一、 浮動電壓源的物理困境

在節點電壓法中，我們選擇一個參考節點（接地點，電位為 $0\text{ V}$），其餘 $N$ 個節點電壓為狀態變數。對任意一般節點 $k$，KCL 方程式為：

$$\sum_{j \in \text{neighbors}} \frac{v_k - v_j}{R_{kj}} + \sum i_{\text{source}} = 0$$

### 為什麼浮動電壓源會使傳統列式崩潰？
當節點 $m$ 與節點 $n$ 之間連有電壓源 $V_s$ 時：
1. 理想電壓源內部阻抗為零：$R_v = 0$。
2. 支路電流 $i_v = \frac{v_m - v_n}{0}$，分母為零，數學上無定義。
3. 若視 $i_v$ 為獨立未知變數，則原本 $N$ 個節點電壓加上 $k$ 個未知支路電流，需要 $N + k$ 條獨立方程式，傳統純節點 KCL 無法自動提供足夠的閉合關係。

## 二、 廣義高斯面（超節點）包絡原理

依據電荷守恆定律，在準靜態電磁學中，流入任何封閉幾何曲面 $S$ 的傳導電流總和必為零：

$$\oint_S \mathbf{J} \cdot d\mathbf{A} = 0 \implies \sum_{\text{crossing } S} i_{\text{in}} = \sum_{\text{crossing } S} i_{\text{out}}$$

### 超節點包絡的兩大代數優勢
- **內部電流自動抵消**：電壓源內部的未知電流 $i_v$ 從節點 $m$ 流入節點 $n$，兩端點皆位於曲面 $S$ 內部。因此在積分時，正負電流完全抵消，不進入外邊界通量計算。
- **並聯支路自動吸收**：任何跨接在節點 $m$ 與 $n$ 之間的並聯電阻，其電流 $\frac{v_m - v_n}{R_p}$ 亦為曲面內部的循環電流，同樣自動抵消。

## 三、 方程式維度不變性分析 (Dimensional Invariance)

設電路共有 $N$ 個非參考節點，其中包含 $k$ 個跨接在兩非參考節點之間的電壓源：

| 方程式類型 | 數量 | 物理來源 |
| :--- | :--- | :--- |
| **超節點廣義 KCL** | $k$ 個超節點，各提供 1 條 | 封閉面包絡之電荷守恆定律 |
| **獨立普通節點 KCL** | $N - 2k$ 個獨立節點 | 個別節點之 KCL 電流守恆 |
| **電壓源拘束方程式** | $k$ 條 | 電壓源定義：$v_{\text{pos}} - v_{\text{neg}} = V_s$ |
| **總方程式數量** | **$N$ 條** | **剛好嚴格等於 $N$ 個未知節點電壓** |

這證明了超節點技術保證了線性方程組 $[A]\mathbf{v} = \mathbf{b}$ 依然是 $N \times N$ 的滿秩方陣，在電路拓撲可實現的前提下必有唯一解。
