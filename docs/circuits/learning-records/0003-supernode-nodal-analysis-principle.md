# 超節點分析法 (Supernode Analysis) 的物理包絡原理與拘束方程式架構

建立處理含有「浮動電壓源（跨接於兩非參考節點之間）」之節點分析法第一原理框架。透過將電壓源及其並聯元件包絡為廣義封閉高斯面（超節點），成功避開電壓源內部未知電流 $i_v$ 無法用歐姆定律表達的致命困難，並結合電壓源兩端電位差之「拘束方程式（Constraint Equation）」，建構完整的 $N$ 元一次聯立方程組解題體系。

## Evidence
- 深入剖析為何理想電壓源內阻為零導致常規 KCL 無法為該支路提供歐姆定律電流表達式。
- 完整推導廣義超節點邊界電流守恆（$\sum i_{\text{in}} = \sum i_{\text{out}}$）與電壓拘束式（$v_{\text{pos}} - v_{\text{neg}} = V_s$）之數學閉合性。
- 實作互動式超節點即時數值模擬器，驗證 Example 3.3 與相依電壓源 Example 3.4 之雙重超節點解題結構。
- 完成概念檢索測驗（Retrieval Practice），鞏固「超節點 KCL 數量 + 電壓拘束式數量 = 待求節點總數」之維度不變性。

## Implications
- 徹底消除面對浮動電壓源時不知如何列寫 KCL 的困惑，能快速標定超節點邊界並準確列寫拘束方程式。
- 為後續「網孔分析法之超網孔（Supermesh，處理兩網孔共用電流源）」提供完美的對偶思維基礎（電壓源 $\leftrightarrow$ 電流源、超節點 $\leftrightarrow$ 超網孔、KCL $\leftrightarrow$ KVL）。
