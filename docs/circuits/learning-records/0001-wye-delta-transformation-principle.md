# 0001: 星形與三角形網路等效互換原理與幾何對偶

> 建立「外端等效特性 (Terminal Equivalence)」之第一原理推導框架與電導對偶性

##  學習紀錄核心重點

本單元建立三端線性電阻網路在外部激勵下的外端等效框架。透過端點開路等效阻抗聯立方程組解出 $R_1, R_2, R_3$ 與 $R_a, R_b, R_c$ 雙向轉換，掌握「相鄰乘積除以總和」與「兩兩積和除以對邊」之幾何記憶法與電導對偶性，為非平衡電橋網路化簡與交流三相電路分析奠定理論基石。

---

## 一、 外端等效性的嚴格數學定義

設一無獨立電源的三端線性網路具有三個外露端點 $a, b, c$。
若令端點 $c$ 為參考節點，端點 $a, b$ 的端電壓向量為 $\mathbf{v} = [v_a, v_b]^T$，流入端點的端電流向量為 $\mathbf{i} = [i_a, i_b]^T$。

根據線性電路理論，該網路之外端特性可由雙埠阻抗矩陣（Z-parameters）完全表徵：

$$\mathbf{v} = \mathbf{Z} \mathbf{i} = \begin{bmatrix} z_{11} & z_{12} \\ z_{21} & z_{22} \end{bmatrix} \begin{bmatrix} i_a \\ i_b \end{bmatrix}$$

- **可逆性與對稱性**：對於純電阻無相依源網路，$z_{12} = z_{21}$，獨立參數僅有 3 個。
- **等效條件**：若星形網路與三角形網路具有完全相同的 $\mathbf{Z}$ 矩陣（或導納矩陣 $\mathbf{Y}$），則對於外部任意電路激勵而言，兩網路完全不可區分。

---

## 二、 開路端阻抗聯立消去之代數結構

透過依序令端點 $c$、$a$、$b$ 開路，得到三組端點等效電阻：

$$R_{ab} = R_1 + R_2 = R_c \parallel (R_a + R_b) = \frac{R_c (R_a + R_b)}{R_a + R_b + R_c}$$
$$R_{bc} = R_2 + R_3 = R_a \parallel (R_b + R_c) = \frac{R_a (R_b + R_c)}{R_a + R_b + R_c}$$
$$R_{ca} = R_3 + R_1 = R_b \parallel (R_c + R_a) = \frac{R_b (R_c + R_a)}{R_a + R_b + R_c}$$

### 輪換對稱求解
定義 $\Sigma R_\Delta = R_a + R_b + R_c$。聯立相加減：
$$(R_{ab} + R_{ca} - R_{bc}) = (R_1 + R_2) + (R_3 + R_1) - (R_2 + R_3) = 2R_1$$
代入展開分子：
$$(R_a R_c + R_b R_c) + (R_a R_b + R_b R_c) - (R_a R_b + R_a R_c) = 2 R_b R_c$$
因此精確導出：
$$R_1 = \frac{R_b R_c}{\Sigma R_\Delta}$$

---

## 三、 電導觀點下的阻抗-導納對偶性 (Impedance-Admittance Duality)

若改以電導矩陣 $\mathbf{Y} = \mathbf{Z}^{-1}$ 進行分析：
- 星形網路各臂電導為 $G_1 = 1/R_1, G_2 = 1/R_2, G_3 = 1/R_3$。
- 三角形網路各邊電導為 $G_a = 1/R_a, G_b = 1/R_b, G_c = 1/R_c$。

由星形反求三角形電導時：
$$G_a = \frac{G_2 G_3}{G_1 + G_2 + G_3}, \quad G_b = \frac{G_1 G_3}{G_1 + G_2 + G_3}, \quad G_c = \frac{G_1 G_2}{G_1 + G_2 + G_3}$$

> **物理美感**：  
> $\text{Y} \to \Delta$ 的電導公式，其結構形式與 $\Delta \to \text{Y}$ 的電阻公式完全相同（相鄰相乘除以三項總和）。這表明 Y 與 $\Delta$ 在拓撲對偶變換下互為映射。

---

##  學習推論與解題價值 (Implications)

1. 面對複雜多網孔電路時，優先辨識是否存在 $\Delta$ 或 $\text{Y}$ 形狀，透過單次局部互換將不可解的橋式結構降階為純串並聯。
2. 在三相電力系統中，負載的 $\Delta$ 接法與 $\text{Y}$ 接法轉換（$Z_\Delta = 3 Z_\text{Y}$）可直接套用此處推導的單相阻抗等效原理。
