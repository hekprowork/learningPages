# 星形 (Y) 與三角形 (Δ) 網路等效互換原理與幾何對偶法則

建立「外端等效特性（Terminal Equivalence）」之第一原理推導框架，透過端點開路等效阻抗聯立方程組解出 $R_1, R_2, R_3$ 與 $R_a, R_b, R_c$ 雙向轉換，並掌握「相鄰乘積除以總和」與「兩兩積和除以對邊」之幾何記憶法與電導對偶性。這為後續非平衡電橋網路（Bridge Circuits）化簡與交流三相電路分析奠定核心化簡基石。

## Evidence
- 完整推導 $R_{ab}(\text{Y}) = R_1 + R_2$ 與 $R_{ab}(\Delta) = R_c \parallel (R_a + R_b)$ 的聯立代數消去過程。
- 建立對稱三相網路 $R_\Delta = 3 R_\text{Y}$ 之物理成因（兩支臂串聯 vs 跨接並聯）直覺。
- 完成即時等效模擬器與概念檢索小測驗。

## Implications
- 後續解析包含非純串並聯架構之電阻網路時，可直接套用 $\text{Y}-\Delta$ 互換技術將複雜多網孔降階為串並聯組合。
- 解除對公式的死記硬背，具備從第一原理現場驗算之能力。
