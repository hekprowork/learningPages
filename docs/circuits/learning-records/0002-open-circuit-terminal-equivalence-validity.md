# 開路測試在三端網路等效推導中的數學與物理合法性

釐清推導 Y-Δ 互換時「假設端點開路」並非限制實際電路必須開路，而是利用線性非時變（LTI）系統的唯一性定理與雙埠阻抗矩陣（Z-parameters）特性：三端線性網路的外端特性由 3 個獨立線性參數完全決定。透過 3 組獨立的開路邊界條件（ic=0, ia=0, ib=0）所解出的等效參數，能完全代表任意外部激勵條件下的整體外端行為。

## Evidence
- 透過雙埠網路矩陣（Two-port Z/Y matrices）與重疊原理解釋「測試激勵（Probe Condition）」與「全域等效（Global Equivalence）」之差異。
- 類比戴維寧定理（Thevenin）中以開路電壓與短路電流鎖定等效模型之方法論。

## Implications
- 建立了「線性電路特徵萃取」的通用方法論，有助於後續學習雙埠網路（Two-Port Networks）、戴維寧/諾頓等效、以及多端點網路分析。
