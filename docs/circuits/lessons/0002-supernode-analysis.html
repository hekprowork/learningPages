Lesson #0002 · 核心觀念精講

超節點分析法 (Supernode Analysis) 的原理與推導

學科領域：電路學 (Circuit Theory) · 節點分析法 建議時間：12 ~ 15 分鐘 前置關聯：Lesson 0001: Y-Δ 互換 速查索引：0002 超節點速查手冊

學習目標 (Learning Objectives)

在標準的節點電壓法 (Nodal Analysis) 中，我們習慣對每個非參考節點列寫 KCL，並利用歐姆定律 $i = \frac{v_1 - v_2}{R}$ 將各支路電流轉換為電壓未知數。

然而，當電路中出現「夾在兩個非參考節點之間的電壓源」時，標準作法會立刻遇到致命困難：電壓源內部的電流大小是完全未知的，無法用歐姆定律表達！

本課核心收穫

學完本課後，你將深刻理解「超節點（Supernode）」的物理本質（廣義高斯面 / 電荷守恆封閉面包絡），並掌握「超節點 KCL + 電壓源拘束方程式」雙核心解題策略，從容破解任意包含獨立與相依電壓源的複雜節點電路！

1. 第一原理：為什麼標準節點法會「卡住」？

我們先回到物理最底層思考：電壓源的本質是「固定兩端電位差」，但它「對流過自身的電流大小完全不做限制」。

困境剖析：未知的電壓源電流 $i_v$

假設節點 1 與節點 2 之間跨接了一個獨立電壓源 $V_s$。若我們嘗試對節點 1 列 KCL： $$\sum i_{\text{out}} = \frac{v_1 - 0}{R_1} + \frac{v_1 - v_3}{R_2} + i_v = 0$$ 這裡的 $i_v$ 是一個全新的未知數，而且因為理想電壓源的內阻為 $0\ \Omega$，我們無法透過歐姆定律把 $i_v$ 寫成 $\frac{\Delta v}{0}$（分母為零無意義）。

如果我們為每個電壓源多設一個電流未知數 $i_v$，方程式數量將暴增，失去節點電壓法簡潔的優勢。

天才的破局點（The Breakthrough Idea）：
既然電壓源內部的電流 $i_v$ 很麻煩，那我們能不能「把它包起來，不去看它」？

2. 什麼是「超節點 (Supernode)」？

根據克希荷夫電流定律 (KCL) 的廣義形式：流入任何閉合曲面（Closed Surface）的總電流必等於流出該曲面的總電流。

我們將「電壓源本身」以及「與它直接並聯的任何元件」用一個虛擬的封閉紅色邊界圈起來，視為一個單一的廣義節點——這就是超節點 (Supernode)！

超節點的兩大核心特性
  • 特性 1（內部電流隱形）： 電壓源內部的未知電流 $i_v$ 屬於超節點「內部閉環」，在列寫廣義 KCL 時完全不會出現！
  • 特性 2（並聯元件合併）： 任何與該電壓源並聯的元件（例如上圖中頂部的 $10\ \Omega$ 電阻），因為兩端都在同一個超節點內，其分流也屬於內部電流，一併被包絡吸收！

3. 解題核心：超節點的「兩道黃金方程式」

原本節點 1 與節點 2 需要 2 條獨立的 KCL 方程式。現在合併成超節點後，我們只有 1 條超節點 KCL，少了一條方程式怎麼辦？

答案是：電壓源本身的電位差提供了另一條「拘束方程式」！

超節點解題雙核心定律
① 廣義 KCL 方程式 (Supernode KCL)：

將超節點邊界視為一個整體，計算所有「穿透邊界流入/流出」的支路電流總和： $$\sum i_{\text{流入超節點}} = \sum i_{\text{流出超節點}}$$

② 電壓源拘束方程式 (Constraint Equation)：

直接由電壓源正負極與端電壓定義列出兩節點電位關係： $$v_{\text{正極端}} - v_{\text{負極端}} = V_s \quad (\text{或 } \alpha v_x)$$

4. 實戰拆解：Example 3.3 逐行分析

讓我們直接以剛剛示意圖中的經典電路（課本 Example 3.3）進行手把手完整推導：

步驟 1：列寫電壓源拘束方程式

觀察 $2\text{ V}$ 電壓源，正極連接在節點 2，負極連接在節點 1：

$$v_2 - v_1 = 2 \implies v_2 = v_1 + 2 \quad \cdots (1)$$

步驟 2：對超節點 1-2 列寫廣義 KCL

觀察所有穿過紅色虛線框的外部支路電流：

  • 左側：$2\text{ A}$ 電流源流入超節點
  • 下方節點 1：流經 $2\ \Omega$ 電阻流出到接地（$\frac{v_1 - 0}{2}$）
  • 下方節點 2：流經 $4\ \Omega$ 電阻流出到接地（$\frac{v_2 - 0}{4}$）
  • 右側：$7\text{ A}$ 電流源流出超節點

列寫流入 = 流出：

$$2 = \frac{v_1}{2} + \frac{v_2}{4} + 7$$

移項並同乘以 4：

$$\frac{v_1}{2} + \frac{v_2}{4} = 2 - 7 = -5 \implies 2v_1 + v_2 = -20 \quad \cdots (2)$$

步驟 3：聯立求解

將式 $(1)$ $v_2 = v_1 + 2$ 代入式 $(2)$：

$$2v_1 + (v_1 + 2) = -20 \implies 3v_1 = -22 \implies v_1 = -\frac{22}{3}\text{ V} \approx -7.333\text{ V}$$

代回計算 $v_2$：

$$v_2 = -\frac{22}{3} + 2 = -\frac{16}{3}\text{ V} \approx -5.333\text{ V}$$
