Lesson #0001 · 核心觀念精講

星形 (Y) 與等效三角形 (Δ) 網路互換的原理與推導

學科領域：電路學 (Circuit Theory) 建議時間：12 ~ 15 分鐘 速查索引：0001 速查手冊

學習目標 (Learning Objectives)

在複雜電路分析（例如惠斯登電橋、三相電力系統或多端點網孔）中，我們常遇到既非純串聯也非純並聯的電阻組合。 此時，「星形（$\text{Y}$ 或 $\text{T}$ 型）」與「三角形（$\Delta$ 或 $\Pi$ 型）」的等效互換就是破局的關鍵利器。

本課核心收穫

學完本課後，你將不再需要死背公式，而是能從「端點外特性等效」的第一原理出發，在 1 分鐘內清晰推導或心算驗證任意 $\text{Y}-\Delta$ 轉換！

1. 核心物理概念：什麼是「外端等效 (Terminal Equivalence)」？

在電路學中，兩個電路網路被稱為「等效（Equivalent）」，定義為： 「對於這組網路以外的外部電路而言，連入相同的端點時，所量測到的端電壓（Voltage）與端電流（Current）完全相同。」

想像一個黑盒子，外面只露出 $a, b, c$ 三個接線端點。如果黑盒子內部裝的是星形 $\text{Y}$ 網路（包含 $R_1, R_2, R_3$），我們在外面測量任意兩端之間的等效阻抗；當把內部換成等效的三角形 $\Delta$ 網路（包含 $R_a, R_b, R_c$）時，外面的所有電壓、電流測量數據完全無法察覺內部結構的改變。

標準命名記憶原則 (Alexander & Sadiku 課本慣例)
  • 星形 $\text{Y}$ 網路： $R_1, R_2, R_3$ 的下標數字分別對應端點 $a, b, c$。
  • 三角形 $\Delta$ 網路： $R_a, R_b, R_c$ 的下標字母對應其「正對面的頂點」（即 $R_a$ 連在 $b-c$ 間、$R_b$ 連在 $a-c$ 間、$R_c$ 連在 $a-b$ 間）。

2. 嚴謹數學推導：由開路端阻抗建立方程組

為了求得六個電阻之間的換算關係，我們逐一將第三個端點開路（Open Circuit），並令兩網路在其餘兩端點間的輸入電阻相等：

(1) 將端點 $c$ 開路，測量 $a-b$ 兩端的等效電阻 $R_{ab}$：

  • 在 $\text{Y}$ 網路中： 端點 $c$ 開路後，$R_3$ 無電流流過，路徑僅為 $R_1$ 與 $R_2$ 串聯： $$R_{ab}(\text{Y}) = R_1 + R_2$$
  • 在 $\Delta$ 網路中： 端點 $c$ 開路後，從 $a$ 到 $b$ 的路徑包含兩條並聯支路 —— 一條是單獨的 $R_c$，另一條是 $R_b$ 與 $R_a$ 串聯： $$R_{ab}(\Delta) = R_c \parallel (R_a + R_b) = \frac{R_c (R_a + R_b)}{R_a + R_b + R_c}$$

令兩者相等，得到第一式：

$$R_1 + R_2 = \frac{R_c (R_a + R_b)}{R_a + R_b + R_c} = \frac{R_a R_c + R_b R_c}{R_a + R_b + R_c} \quad \text{--- (式 1)}$$

(2) 同理，將端點 $a$ 開路，測量 $b-c$ 兩端的等效電阻 $R_{bc}$：

$$R_2 + R_3 = \frac{R_a (R_b + R_c)}{R_a + R_b + R_c} = \frac{R_a R_b + R_a R_c}{R_a + R_b + R_c} \quad \text{--- (式 2)}$$

(3) 同理，將端點 $b$ 開路，測量 $c-a$ 兩端的等效電阻 $R_{ca}$：

$$R_3 + R_1 = \frac{R_b (R_c + R_a)}{R_a + R_b + R_c} = \frac{R_b R_c + R_a R_b}{R_a + R_b + R_c} \quad \text{--- (式 3)}$$

3. 求解 $\Delta \to \text{Y}$ 轉換公式 (三角形轉星形)

我們有包含未知數 $R_1, R_2, R_3$ 的三元一次聯立方程組 (式 1, 式 2, 式 3)。我們可以用非常對稱優雅的代數消去法求解：

步驟 A： 將 (式 1) 減去 (式 2)，消去共同項 $R_2$：

$$(R_1 + R_2) - (R_2 + R_3) = R_1 - R_3 = \frac{(R_a R_c + R_b R_c) - (R_a R_b + R_a R_c)}{R_a + R_b + R_c} = \frac{R_b R_c - R_a R_b}{R_a + R_b + R_c} \quad \text{--- (式 4)}$$

步驟 B： 將 (式 4) 與 (式 3) 相加，消去 $R_3$ 即可獨立解出 $R_1$：

$$(R_1 - R_3) + (R_3 + R_1) = 2 R_1 = \frac{(R_b R_c - R_a R_b) + (R_b R_c + R_a R_b)}{R_a + R_b + R_c} = \frac{2 R_b R_c}{R_a + R_b + R_c}$$ $$\implies R_1 = \frac{R_b R_c}{R_a + R_b + R_c}$$

步驟 C： 根據電路的輪換對稱性（Cyclic Symmetry），直接寫出 $R_2$ 與 $R_3$：

⚡ $\Delta \to \text{Y}$ 轉換核心公式

代數表達式

$$R_1 = \frac{R_b R_c}{R_a + R_b + R_c}$$ $$R_2 = \frac{R_a R_c}{R_a + R_b + R_c}$$ $$R_3 = \frac{R_a R_b}{R_a + R_b + R_c}$$

幾何直覺口訣

$$R_{\text{star}} = \frac{\text{相鄰兩邊之積}}{\text{三邊之總和}}$$

例如 $R_1$ 連向節點 $a$，在 $\Delta$ 中夾住頂點 $a$ 的兩條相鄰邊就是 $R_b$ 與 $R_c$！

4. 求解 $\text{Y} \to \Delta$ 轉換公式 (星形轉三角形)

若已知星形電阻 $R_1, R_2, R_3$，如何反求外圍的三角形電阻 $R_a, R_b, R_c$？ 直接暴力代換十分繁瑣，這裡有一個極致優雅的代數技巧 ——「兩兩乘積求和」：

我們將剛剛得到的 $R_1, R_2, R_3$ 兩兩相乘並加總：

$$R_1 R_2 + R_2 R_3 + R_3 R_1 = \frac{(R_b R_c)(R_a R_c) + (R_a R_c)(R_a R_b) + (R_a R_b)(R_b R_c)}{(R_a + R_b + R_c)^2}$$ $$= \frac{R_a R_b R_c^2 + R_a^2 R_b R_c + R_a R_b^2 R_c}{(R_a + R_b + R_c)^2} = \frac{R_a R_b R_c (R_c + R_a + R_b)}{(R_a + R_b + R_c)^2} = \frac{R_a R_b R_c}{R_a + R_b + R_c} \quad \text{--- (式 5)}$$

觀察 (式 5) 的分子分母，只要將 (式 5) 除以 $R_1 = \frac{R_b R_c}{R_a + R_b + R_c}$，其中的 $R_b R_c$ 與分母將全部消去，奇蹟般地只剩下 $R_a$！

$$\frac{R_1 R_2 + R_2 R_3 + R_3 R_1}{R_1} = \frac{\frac{R_a R_b R_c}{R_a + R_b + R_c}}{\frac{R_b R_c}{R_a + R_b + R_c}} = R_a$$

同理，除以 $R_2$ 得到 $R_b$，除以 $R_3$ 得到 $R_c$：

⚡ $\text{Y} \to \Delta$ 轉換核心公式

代數表達式

$$R_a = \frac{R_1 R_2 + R_2 R_3 + R_3 R_1}{R_1}$$ $$R_b = \frac{R_1 R_2 + R_2 R_3 + R_3 R_1}{R_2}$$ $$R_c = \frac{R_1 R_2 + R_2 R_3 + R_3 R_1}{R_3}$$

幾何直覺口訣

$$R_{\Delta} = \frac{\text{兩兩相乘之總和}}{\text{正對面之電阻}}$$

例如求外圍底邊的 $R_a$，分子是三組乘積總和，分母就是頂部正對著它的 $R_1$！

5. 深度洞察：平衡對稱特例與電導對偶性 (Insights)

Insight 1：三相平衡/對稱電阻的 $3$ 倍規律

當三相電阻完全相等時（即 $R_1 = R_2 = R_3 = R_\text{Y}$，且 $R_a = R_b = R_c = R_\Delta$）：

$$R_\Delta = \frac{R_\text{Y}^2 + R_\text{Y}^2 + R_\text{Y}^2}{R_\text{Y}} = \frac{3 R_\text{Y}^2}{R_\text{Y}} = 3 R_\text{Y}$$ $$R_\text{Y} = \frac{R_\Delta \cdot R_\Delta}{3 R_\Delta} = \frac{1}{3} R_\Delta$$

為什麼三角形電阻恰好是星形的 3 倍？
物理直覺：在星形中，電流從端點 $a$ 走到 $b$ 必須穿過兩支串聯臂（阻抗 $2 R_\text{Y}$）；在三角形中，電流同時走直接跨接支路與外圍串聯支路並聯（$R_\Delta \parallel 2 R_\Delta = \frac{2}{3} R_\Delta$）。令 $2 R_\text{Y} = \frac{2}{3} R_\Delta$，立即得到 $R_\Delta = 3 R_\text{Y}$！

Insight 2：電導 (Conductance $G$) 的對偶完美對稱性

若改以電導 $G = 1/R$ 表示，$\text{Y} \to \Delta$ 的轉換公式會呈現驚人的對稱性：

$$G_a = \frac{G_2 G_3}{G_1 + G_2 + G_3}, \quad G_b = \frac{G_1 G_3}{G_1 + G_2 + G_3}, \quad G_c = \frac{G_1 G_2}{G_1 + G_2 + G_3}$$

驚人發現： 用電導看 $\text{Y} \to \Delta$，其數學形式與用電阻看 $\Delta \to \text{Y}$ 一模一樣（相鄰乘積除以總和）！這正是電路理論中「阻抗-導納對偶性（Duality）」的完美體現。

7. 實戰經典範例：非平衡電橋網路化簡 (Bridge Circuit)

考慮課堂經典習題（Example 2.15）：一個由 5 個電阻構成的非平衡電橋，直接串並聯無法化簡。

標準化簡三部曲
  1. 圈出三角形： 將電路上半部的網孔視為一個由端點 $a, b, c$ 圍成的 $\Delta$ 網路。
  2. 代入口訣換成星形： 利用「相鄰相乘除以總和」算出等效星形的三支臂 $R_1, R_2, R_3$。
  3. 直接串並聯： 轉換後，中央星點 $n$ 向下分出兩條獨立的支路，分別與電路下半部的兩顆電阻串聯，再並聯求總阻抗，秒殺全題！
