# 002: 超節點分析法 (Supernode Analysis) 核心速查手冊 (Supernode Reference)

> 彙整浮動電壓源處理決策流程、超節點 4 步標準解題演算法與易錯地雷清單

## 一、 電壓源處理決策流程 (Decision Workflow)

| 電壓源位置 | 電路特徵 | 標準處理手法 | 方程式貢獻 |
| :--- | :--- | :--- | :--- |
| **接在接地端與非參考節點間** | 電壓源一端直接接地 ($0\text{ V}$) | **直接定值 (Trivial)**<br>該節點電壓直接等於電壓源值：$v_k = V_s$ | 直接消去 1 個未知數，無需對該節點列寫 KCL。 |
| **接在兩非參考節點之間** | 電壓源兩端皆浮動（未接地） | **超節點 (Supernode)**<br>將電壓源包絡為廣義節點列寫 KCL，並補上電壓拘束式 | 1 條超節點 KCL + 1 條電壓拘束式：<br>$v_{\text{pos}} - v_{\text{neg}} = V_s$ |

## 二、 超節點 4 步標準解題演算法 (Standard 4-Step Algorithm)

```
[STEP 1: 框出超節點邊界] ───> [STEP 2: 寫出電壓拘束式]
           │                              │
           ▼                              ▼
[STEP 3: 列寫超節點廣義 KCL] ───> [STEP 4: 聯立消去求解]
```

1. **STEP 1 · 識別包絡**：  
   將所有夾在非參考節點間的電壓源（及其並聯元件）畫上封閉邊界框，標定內部節點電壓（如 $v_1, v_2$）。
2. **STEP 2 · 拘束列式**：  
   觀察電壓源正負極性，列出拘束方程式：
   $$v_{\text{正極}} - v_{\text{負極}} = V_s \quad (\text{或相依源 } \alpha v_x)$$
   若為相依源，需將控制量 $v_x, i_x$ 以節點電壓替換。
3. **STEP 3 · 廣義 KCL**：  
   計算所有穿透邊界流入/流出的支路電流：
   $$\sum i_{\text{流入邊界}} = \sum i_{\text{流出邊界}}$$
   內部支路電流完全不列入！
4. **STEP 4 · 聯立求解**：  
   將拘束式代入 KCL 消除變數，或組成標準矩陣方程式 $[A][v] = [b]$ 求解。

## 三、 易錯盲點自我檢查清單 (Pitfalls & Sanity Checks)

::: warning 四大常見失分地雷
1. **把電壓源內部電阻重複計算**：與電壓源並聯的電阻屬於超節點內部閉環，在列寫超節點 KCL 時**絕對不能**重複寫入！
2. **電壓源正負極性減反**：拘束式必為**「正極端電位 − 負極端電位 = 電源值」**。若正極接節點 2、負極接節點 1，則是 $v_2 - v_1 = V_s$，切勿寫成 $v_1 - v_2$。
3. **漏列未包絡的一般節點 KCL**：電路中未與電壓源相連的一般節點，依然需要各自列寫一條標準 KCL。
4. **相依源控制變數未替換**：若電壓源為相依源（如 $3v_x$ 或 $\beta i_x$），在求解前必須先將控制量寫為節點電壓差或歐姆定律分壓。
:::
