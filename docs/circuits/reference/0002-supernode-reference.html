2. 超節點 4 步標準解題演算法 (Standard 4-Step Algorithm)

STEP 1 · 識別包絡

框出超節點邊界

將所有夾在非參考節點間的電壓源（及其並聯元件）畫上虛線框，標定內部節點電壓（如 $v_1, v_2$）。

STEP 2 · 拘束列式

寫出電壓拘束式

觀察電壓源正負極性，列出： $$v_{\text{正極}} - v_{\text{負極}} = V_s \quad (\text{或 } \alpha v_x)$$ 若為相依源，需將控制量 $v_x, i_x$ 轉換為節點電壓。

STEP 3 · 廣義 KCL

列寫超節點 KCL

計算所有穿透虛線邊界流入/流出的支路電流： $$\sum i_{\text{流入邊界}} = \sum i_{\text{流出邊界}}$$ 內部支路電流完全不列入！

STEP 4 · 聯立求解

矩陣或代入消去

將拘束式代入 KCL 消除變數，或組成標準矩陣方程式 $[A][v] = [b]$ 透過克拉瑪法則 (Cramer's Rule) 求解。

3. 易錯盲點自我檢查清單 (Pitfalls & Sanity Checks)

四大常見失分地雷
  1. 把電壓源內部電阻重複計算： 與電壓源並聯的電阻屬於超節點內部，在列寫超節點 KCL 時絕對不能重複寫入（例如 Example 3.3 頂部的 $10\ \Omega$ 電阻）！
  2. 電壓源正負極性減反： 拘束式一定是「正極端電位 − 負極端電位 = 電源值」。若正極接在節點 2、負極接在節點 1，則是 $v_2 - v_1 = V_s$，切勿寫成 $v_1 - v_2$。
  3. 漏列未包絡的一般節點 KCL： 若電路中還有其他未與電壓源相連的一般節點，別忘了它們依然需要各自列寫一條標準 KCL。
  4. 相依源控制變數未替換： 若電壓源為相依源（如 $3v_x$ 或 $\beta i_x$），必須在列式前先找出 $v_x = v_a - v_b$ 或 $i_x = \frac{v_a - v_b}{R}$，將控制量徹底用節點電壓替換。
