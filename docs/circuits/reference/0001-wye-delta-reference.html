星形 (Y) 與三角形 (Δ) 網路等效互換速查手冊

學科：電路學 (Electric Circuits) 適用章節：Chapter 2 / 三端網路等效化簡 對應課程：Lesson 0001 原理精講

1. 網路拓撲與標準命名慣例 (Topology & Conventions)

標準命名關鍵原則

Δ 網路電阻下標對應其正對面頂點：$R_a$ 對面是節點 $a$（連在 $b-c$ 間）、$R_b$ 對面是節點 $b$（連在 $a-c$ 間）、$R_c$ 對面是節點 $c$（連在 $a-b$ 間）。

2. 互換公式與極速解題口訣

Δ → Y (三角形轉星形)

求星形內部分支電阻 $R_1, R_2, R_3$

核心口訣：
「相鄰兩邊之積 ÷ 三邊總和」

$$R_1 = \frac{R_b R_c}{R_a + R_b + R_c}$$ $$R_2 = \frac{R_a R_c}{R_a + R_b + R_c}$$ $$R_3 = \frac{R_a R_b}{R_a + R_b + R_c}$$

直覺定位： $R_1$ 接在節點 $a$，在 Δ 中與節點 $a$ 相鄰的兩邊為 $R_b$ 與 $R_c$。

Y → Δ (星形轉三角形)

求外圍三角形電阻 $R_a, R_b, R_c$

核心口訣：
「兩兩相乘之和 ÷ 正對面電阻」

$$R_a = \frac{R_1 R_2 + R_2 R_3 + R_3 R_1}{R_1}$$ $$R_b = \frac{R_1 R_2 + R_2 R_3 + R_3 R_1}{R_2}$$ $$R_c = \frac{R_1 R_2 + R_2 R_3 + R_3 R_1}{R_3}$$

直覺定位： 分子為輪換乘積和 $\sum R_i R_j$；分母為正對面頂點連向中心之電阻。

3. 對稱平衡特例與電導對偶性 (Shortcuts & Duality)

情境 / 視角 星形 (Y) 參數 三角形 (Δ) 參數 等效換算關係
平衡對稱電阻
(Symmetric Resistors)		 $R_1 = R_2 = R_3 = R_\text{Y}$ $R_a = R_b = R_c = R_\Delta$ $$R_\Delta = 3 R_\text{Y} \iff R_\text{Y} = \frac{1}{3} R_\Delta$$ (口訣：三角形電阻是星形的 3 倍)
電導觀點對偶
(Conductance $G = 1/R$)		 $G_1, G_2, G_3$ $G_a, G_b, G_c$ $$G_a = \frac{G_2 G_3}{G_1 + G_2 + G_3}$$ (Y→Δ 電導公式形式與 Δ→Y 電阻完全相同！)

4. 經典電橋網路（Bridge Circuit）標準解題 3 步驟

  1. 識別阻礙： 檢查電橋對角乘積是否平衡 ($R_1 R_4 \stackrel{?}{=} R_2 R_3$)。若不平衡且中間有跨接電阻，則無法直接串並聯。
  2. 局部轉換： 將上方（或下方）之三角形網孔 $\Delta$ 轉為星形 $\text{Y}$（或將左/右側 $\text{T}$ 轉為 $\Pi$）。
  3. 串並聯求總阻： 轉換後，中央星點向下分出兩條獨立支路，電路退化為標準「兩組串聯再並聯，最後加上頂部電阻」結構，直接口算總電阻。
