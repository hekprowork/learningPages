# User Notes & Preferences

- **教學語言**: 繁體中文（專業術語保留英文對照，例如 Wye-Delta / Star-Delta / 星形-三角形、Conductance / 電導）。
- **教學風格**: 原理優先（First Principles）、兼顧幾何直覺與數學嚴謹推導，拒絕枯燥死記；提供互動式驗證與檢索練習以建立長期儲存強度（Storage Strength）。
- **符號規範**: 與 Alexander & Sadiku 課本及課堂簡報一致：
  - 星形 Y / T 網路：三端點 $a, b, c$，中心節點 $n$，電阻分別為 $R_1$（接 $a$）、$R_2$（接 $b$）、$R_3$（接 $c$）。
  - 三角形 $\Delta / \Pi$ 網路：三端點 $a, b, c$，電阻 $R_a$（$b-c$ 間，對應節點 $a$）、$R_b$（$a-c$ 間，對應節點 $b$）、$R_c$（$a-b$ 間，對應節點 $c$）。
