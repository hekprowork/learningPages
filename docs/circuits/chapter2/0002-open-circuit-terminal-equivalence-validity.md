# 0002: 開路測試在三端網路等效推導中的數學與物理合法性

> 剖析推導中「假設端點開路」與線性非時變 (LTI) 唯一性定理之關聯

## 🎯 學習紀錄核心重點

初學者在學習 Y-Δ 互換時常產生疑惑：「推導時明明假設第三個端點開路（$i_c = 0$），那在實際電路中該端點接有負載或有電流流過時，這些公式依然成立嗎？」

本紀錄釐清推導 Y-Δ 互換時「假設端點開路」並非限制實際電路必須開路，而是利用**線性非時變（LTI）系統的唯一性定理**與**雙埠阻抗矩陣（Z-parameters）特性**：三端線性網路的外端特性由 3 個獨立線性參數完全決定。透過 3 組獨立的開路邊界條件（$i_c = 0, i_a = 0, i_b = 0$）所解出的等效參數，能完全代表任意外部激勵條件下的整體外端行為。

---

## 一、 線性電路的唯一性定理與自由度分析

一個由純線性電阻構成的三端網路（端點 $a, b, c$），其外端端電壓與端電流滿足基爾霍夫定律與歐姆定律：

$$\begin{bmatrix} v_a - v_c \\ v_b - v_c \end{bmatrix} = \begin{bmatrix} z_{11} & z_{12} \\ z_{21} & z_{22} \end{bmatrix} \begin{bmatrix} i_a \\ i_b \end{bmatrix}$$

由於滿足互易定理（Reciprocity Theorem），阻抗矩陣為對稱矩陣：
$$z_{12} = z_{21}$$

因此，決定該三端網路外端電氣特性的獨立未知數**恰好只有 3 個**（$z_{11}, z_{22}, z_{12}$）。

---

## 二、 測試激勵 (Probe Condition) vs 全域等效 (Global Equivalence)

在數學物理中，要唯一確定一個包含 3 個未知參數的線性算子，只需施加 **3 組線性獨立的測試邊界條件**：

1. **測試條件 1**：令 $i_c = 0, i_b = -i_a$，測得端電阻 $R_{ab}$。
2. **測試條件 2**：令 $i_a = 0, i_c = -i_b$，測得端電阻 $R_{bc}$。
3. **測試條件 3**：令 $i_b = 0, i_a = -i_c$，測得端電阻 $R_{ca}$。

這三組測試條件在向量空間中彼此線性獨立。只要星形網路與三角形網路在這 3 組獨立測試下的外端響應完全相同，則根據線性疊加原理（Superposition Theorem）：

$$\mathbf{v}_{\text{total}} = \mathbf{Z} \mathbf{i}_{\text{total}} = \mathbf{Z} (\alpha \mathbf{i}_1 + \beta \mathbf{i}_2 + \gamma \mathbf{i}_3)$$

兩者在**任意外部電壓、任意外部電流**激勵下的整體行為**必然處處等效**！

---

## 三、 與戴維寧定理 (Thévenin) 的方法論類比

這種「以特定邊界鎖定全域模型」的方法是電路學的一貫哲學：
- 在戴維寧定理中，我們藉由**「開路電壓 $v_{oc}$」**（$i=0$ 的極限）與**「短路電流 $i_{sc}$」**（$v=0$ 的極限）鎖定電路的等效模型。
- 模型一旦建立，它就能準確預測接上**任意負載電阻 $R_L$** 時的電壓與電流。
- 同理，Y-Δ 互換中的開路操作只是一種「特徵參數萃取法」，而非對工作狀態的限制。
