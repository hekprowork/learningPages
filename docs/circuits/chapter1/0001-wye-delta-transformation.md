# Lesson 0001: 星形 (Y) 與等效三角形 (Δ) 網路互換原理與推導

> 掌握三端電阻網路外端等效性的第一原理推導、幾何直覺口訣與電導對偶性

## 🎯 本單元目標

在複雜電路分析（如非平衡電橋、多網孔網路或三相電力系統）中，常遇到既非純串聯也非純並聯的電阻組合。星形（$\text{Y}$ 或 $\text{T}$ 型）與三角形（$\Delta$ 或 $\Pi$ 型）等效互換是化簡此類網路的核心利器。

讀完本課後，你將能夠：
- 從「外端等效特性（Terminal Equivalence）」第一原理自主列寫聯立方程並推導換算公式。
- 熟練運用幾何記憶口訣，在 30 秒內完成 $\Delta \to \text{Y}$ 與 $\text{Y} \to \Delta$ 雙向轉換。
- 深刻理解平衡對稱特例（$R_\Delta = 3 R_\text{Y}$）之物理成因與電導（Conductance $G$）對偶美感。
- 將非平衡電橋網路（Bridge Circuit）秒殺化簡為標準串並聯電路。

---

## 一、 核心物理概念：什麼是「外端等效 (Terminal Equivalence)」？

在電路學中，兩個電路網路被稱為**「等效（Equivalent）」**，其嚴格定義為：

> **外端等效定義**：  
> 對於這組網路以外的外部電路而言，連入相同的端點時，所量測到的端電壓（Voltage）與端電流（Current）完全相同。

想像一個黑盒子，外面只露出 $a, b, c$ 三個接線端點：
- 黑盒子內部裝有**星形 $\text{Y}$ 網路**（包含連至中心點 $n$ 的三個分支電阻 $R_1, R_2, R_3$）。
- 黑盒子內部換裝等效的**三角形 $\Delta$ 網路**（包含外圍三邊電阻 $R_a, R_b, R_c$）。
- 外部電路無論在 $a, b, c$ 施加任何電壓或抽取任何電流，**皆無法察覺內部結構的置換**。

::: tip 💡 Alexander & Sadiku 標準命名慣例
- **星形 $\text{Y}$ 網路**：$R_1$ 連向端點 $a$、$R_2$ 連向端點 $b$、$R_3$ 連向端點 $c$。
- **三角形 $\Delta$ 網路**：電阻下標對應其**正對面的頂點**：
  - $R_a$ 連在 $b-c$ 端點之間（正對面為端點 $a$）。
  - $R_b$ 連在 $a-c$ 端點之間（正對面為端點 $b$）。
  - $R_c$ 連在 $a-b$ 端點之間（正對面為端點 $c$）。
:::

## 二、 嚴謹數學推導：由開路端阻抗建立方程組

為了求得兩組電阻間的換算關係，我們逐一**將第三個端點開路（Open Circuit）**，並令兩網路在其餘兩端點間的輸入阻抗相等：

### 1. 將端點 $c$ 開路，測量 $a-b$ 端等效電阻 $R_{ab}$
- **星形 $\text{Y}$ 網路**：端點 $c$ 開路，$R_3$ 無電流，路徑僅為 $R_1$ 與 $R_2$ 串聯：
  $$R_{ab}(\text{Y}) = R_1 + R_2$$
- **三角形 $\Delta$ 網路**：端點 $c$ 開路，從 $a$ 到 $b$ 的路徑為 $R_c$ 與 $(R_a + R_b)$ 並聯：
  $$R_{ab}(\Delta) = R_c \parallel (R_a + R_b) = \frac{R_c (R_a + R_b)}{R_a + R_b + R_c}$$

令兩者相等，得到**第一式**：
$$R_1 + R_2 = \frac{R_a R_c + R_b R_c}{R_a + R_b + R_c} \quad \text{--- (1)}$$

### 2. 同理，將端點 $a$ 開路，測量 $b-c$ 端等效電阻 $R_{bc}$
$$R_2 + R_3 = \frac{R_a R_b + R_a R_c}{R_a + R_b + R_c} \quad \text{--- (2)}$$

### 3. 同理，將端點 $b$ 開路，測量 $c-a$ 端等效電阻 $R_{ca}$
$$R_3 + R_1 = \frac{R_a R_b + R_b R_c}{R_a + R_b + R_c} \quad \text{--- (3)}$$

---

## 三、 求解 $\Delta \to \text{Y}$ 轉換公式 (三角形轉星形)

利用輪換對稱消去法：

1. 將式 (1) 減去式 (2)，消去共同項 $R_2$：
   $$(R_1 + R_2) - (R_2 + R_3) = R_1 - R_3 = \frac{R_b R_c - R_a R_b}{R_a + R_b + R_c} \quad \text{--- (4)}$$
2. 將式 (4) 與式 (3) 相加，消去 $R_3$：
   $$(R_1 - R_3) + (R_3 + R_1) = 2R_1 = \frac{2 R_b R_c}{R_a + R_b + R_c} \implies R_1 = \frac{R_b R_c}{R_a + R_b + R_c}$$
3. 依循環對稱性寫出其餘兩式：

::: tip ⚡ $\Delta \to \text{Y}$ 核心公式與幾何口訣
$$R_1 = \frac{R_b R_c}{R_a + R_b + R_c}, \quad R_2 = \frac{R_a R_c}{R_a + R_b + R_c}, \quad R_3 = \frac{R_a R_b}{R_a + R_b + R_c}$$

> **幾何直覺口訣**：  
> $$R_{\text{星形臂}} = \frac{\text{相鄰兩邊之積}}{\text{三邊之總和}}$$  
> 例如 $R_1$ 連向節點 $a$，在 $\Delta$ 中夾住頂點 $a$ 的相鄰兩邊就是 $R_b$ 與 $R_c$！
:::

## 四、 求解 $\text{Y} \to \Delta$ 轉換公式 (星形轉三角形)

若已知 $R_1, R_2, R_3$，如何反求外圍的 $R_a, R_b, R_c$？此處運用**「兩兩乘積求和」**的代數技巧：

將 $R_1, R_2, R_3$ 兩兩相乘並加總：
$$R_1 R_2 + R_2 R_3 + R_3 R_1 = \frac{(R_b R_c)(R_a R_c) + (R_a R_c)(R_a R_b) + (R_a R_b)(R_b R_c)}{(R_a + R_b + R_c)^2}$$
$$= \frac{R_a R_b R_c (R_a + R_b + R_c)}{(R_a + R_b + R_c)^2} = \frac{R_a R_b R_c}{R_a + R_b + R_c} \quad \text{--- (5)}$$

將式 (5) 除以 $R_1 = \frac{R_b R_c}{R_a + R_b + R_c}$：
$$\frac{R_1 R_2 + R_2 R_3 + R_3 R_1}{R_1} = \frac{\frac{R_a R_b R_c}{R_a + R_b + R_c}}{\frac{R_b R_c}{R_a + R_b + R_c}} = R_a$$

同理可得 $R_b$ 與 $R_c$：

::: tip ⚡ $\text{Y} \to \Delta$ 核心公式與幾何口訣
$$R_a = \frac{R_1 R_2 + R_2 R_3 + R_3 R_1}{R_1}$$
$$R_b = \frac{R_1 R_2 + R_2 R_3 + R_3 R_1}{R_2}$$
$$R_c = \frac{R_1 R_2 + R_2 R_3 + R_3 R_1}{R_3}$$

> **幾何直覺口訣**：  
> $$R_{\Delta} = \frac{\text{兩兩相乘之總和}}{\text{正對面之電阻}}$$  
> 例如求底邊的 $R_a$，分子是三組乘積總和，分母即為正對著它的星形頂部電阻 $R_1$！
:::

## 五、 深度洞察：平衡對稱特例與電導對偶性

### 1. 三相平衡/對稱電阻的 $3$ 倍規律
當三邊電阻完全對稱時（$R_1 = R_2 = R_3 = R_\text{Y}$，且 $R_a = R_b = R_c = R_\Delta$）：
$$R_\Delta = \frac{3 R_\text{Y}^2}{R_\text{Y}} = 3 R_\text{Y} \iff R_\text{Y} = \frac{1}{3} R_\Delta$$

> **物理直覺**：  
> 在星形中，電流從端點 $a$ 到 $b$ 必須穿過兩支串聯臂（阻抗 $2 R_\text{Y}$）；在三角形中，電流同時走直接跨接支路與外圍串聯支路並聯（$R_\Delta \parallel 2 R_\Delta = \frac{2}{3} R_\Delta$）。令 $2 R_\text{Y} = \frac{2}{3} R_\Delta$，立即得到 $R_\Delta = 3 R_\text{Y}$。

### 2. 電導 (Conductance $G = 1/R$) 的對偶完美對稱
改以電導表示時，$\text{Y} \to \Delta$ 的轉換公式為：
$$G_a = \frac{G_2 G_3}{G_1 + G_2 + G_3}, \quad G_b = \frac{G_1 G_3}{G_1 + G_2 + G_3}, \quad G_c = \frac{G_1 G_2}{G_1 + G_2 + G_3}$$
用電導看 $\text{Y} \to \Delta$，其數學形式與用電阻看 $\Delta \to \text{Y}$ **完全一致**（相鄰相乘除以總和），展現了電路阻抗與導納的極致對稱美感。

## 六、 實戰經典範例：非平衡電橋網路化簡 (Bridge Circuit)

面對包含 5 個電阻的非平衡電橋網路（對角乘積不相等）：

1. **圈出三角形網孔**：將電路上半部視為由端點 $a, b, c$ 圍成的 $\Delta$ 網路。
2. **換成等效星形**：利用 $R_{\text{star}} = \frac{\text{相鄰乘積}}{\text{三邊總和}}$，算出 $R_1, R_2, R_3$。
3. **退化為串並聯**：轉換後，中性點 $n$ 向下分出兩條獨立支路，分別與電路下半部的兩顆電阻**各自串聯**，再將兩支路**並聯**，最後加上頂部電阻 $R_1$，立即求出總輸入電阻！

## 七、 實戰自我檢核 (Retrieval Practice)

::: details 📝 題目 1：等效方程式推導的邊界條件
**問題**：在推導 $\Delta \to \text{Y}$ 轉換公式時，建立第一條方程式的基本物理操作是什麼？

**答案與解析**：
將**端點 $c$ 保持開路**，並令兩網路在 $a-b$ 兩端的等效阻抗相等。開路條件使得星形網路呈現單純的 $R_1 + R_2$ 串聯，三角形網路呈現 $R_c \parallel (R_a + R_b)$，從而建立代數等式。
:::

::: details 📝 題目 2：對稱電阻網絡口算
**問題**：若已知三角形網路三邊電阻皆為 $30\ \Omega$，其等效星形網路的各臂電阻值為何？

**答案與解析**：
$$R_\text{Y} = \frac{1}{3} R_\Delta = \frac{30\ \Omega}{3} = 10\ \Omega$$
三角形電阻是星形電阻的 3 倍，反向轉換除以 3 即可口算。
:::

::: details 📝 題目 3：星形轉三角形的分子結構
**問題**：由星形轉三角形 ($\text{Y} \to \Delta$) 求外圍電阻 $R_a$ 時，正確的口訣與算式結構為何？

**答案與解析**：
口訣為**「兩兩相乘之和 ÷ 正對面電阻」**。分子為輪換積和 $R_1 R_2 + R_2 R_3 + R_3 R_1$，分母為正對面頂點之電阻 $R_1$。
:::
