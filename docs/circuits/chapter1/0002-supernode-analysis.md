# Lesson 0002: 超節點分析法 (Supernode Analysis) 的原理與實戰破解

> 掌握節點分析法中處理浮動電壓源的核心利器：廣義高斯面包絡與電壓拘束方程式

## 🎯 本單元目標

在標準的**節點電壓法 (Nodal Analysis)** 中，我們習慣對每個非參考節點列寫 KCL，並利用歐姆定律 $i = \frac{v_1 - v_2}{R}$ 將支路電流寫成節點電壓。

然而，當電路中出現**「跨接在兩個非參考節點之間的電壓源」**時，標準作法會立刻遇到致命困難：*理想電壓源內部的電流大小完全未知，無法用歐姆定律表達！*

讀完本課後，你將能夠：
- 深刻理解超節點（Supernode）的物理本質（廣義封閉面包絡與電荷守恆）。
- 熟練掌握「超節點 KCL + 電壓源拘束方程式」雙核心解題架構。
- 掌握電壓源極性與相依源控制量的精準轉換，從容破解複雜多節點電路。

---

## 一、 第一原理：為什麼標準節點法會「卡住」？

電壓源的物理本質是**「固定兩端電位差」**，但它**「對流過自身的電流大小不做任何約束」**。

::: warning 困境剖析：未知的電壓源電流 $i_v$
假設節點 1 與節點 2 之間跨接了一個獨立電壓源 $V_s$。若我們嘗試對節點 1 列寫 KCL：
$$\sum i_{\text{out}} = \frac{v_1 - 0}{R_1} + \frac{v_1 - v_3}{R_2} + i_v = 0$$

此處的 $i_v$ 是一個**全新的未知數**。因為理想電壓源的內阻為 $0\ \Omega$，我們**無法透過歐姆定律**將 $i_v$ 寫成 $\frac{\Delta v}{0}$。如果為每個電壓源多設一個電流未知數，方程式數量將大幅膨脹。
:::

**破局思維**：既然電壓源內部的電流 $i_v$ 無法直接表達，我們將它**「包絡起來，不看內部」**！

---

## 二、 什麼是「超節點 (Supernode)」？

根據克希荷夫電流定律 (KCL) 的廣義形式：**流入任何閉合曲面（Closed Surface）的總電流必等於流出該曲面的總電流。**

我們將**「跨接電壓源本身」**以及**「與它直接並聯的任何元件」**用一個虛擬的封閉邊界圈起來，視為一個單一的廣義節點——這就是**超節點 (Supernode)**。

### 超節點的兩大核心特性
1. **內部電流隱形**：電壓源內部的未知電流 $i_v$ 屬於超節點內部閉環電流，在列寫穿透邊界的廣義 KCL 時**完全不出現**。
2. **並聯元件合併**：任何與該電壓源並聯的元件（例如兩端均跨在超節點內的電阻），其分流屬於內部循環電流，**一併被包絡吸收，無需列入 KCL**。

---

## 三、 解題核心：超節點的兩道黃金方程式

合併成超節點後，原本兩個獨立節點縮減為一個廣義節點，方程式系統如何閉合？

答案是：**電壓源本身的電位差提供了另一條電壓拘束方程式！**

### ① 廣義 KCL 方程式 (Supernode KCL)
將超節點邊界視為一個整體，計算所有**「穿透邊界流入/流出」**的支路電流代數和：
$$\sum i_{\text{流入邊界}} = \sum i_{\text{流出邊界}}$$

### ② 電壓源拘束方程式 (Constraint Equation)
由電壓源正負極性與端電壓定義直接列出兩節點電位關係：
$$v_{\text{正極端}} - v_{\text{負極端}} = V_s \quad (\text{或 } \alpha v_x)$$

::: tip 💡 方程式維度不變性
若電路有 $N$ 個非參考節點，其中包含 $k$ 個跨接在非參考節點間的電壓源：
$$\text{超節點 KCL 數量 } (N - k) + \text{電壓源拘束式數量 } k = N \text{ 條獨立方程式}$$
方程式數量與未知數完全相符，方程組嚴格閉合可解！
:::

## 四、 實戰拆解：經典 Example 3.3 逐行分析

### 電路配置
- 節點 1：經 $2\ \Omega$ 電阻接地，外部有 $2\text{ A}$ 電流源流入。
- 節點 2：經 $4\ \Omega$ 電阻接地，外部有 $7\text{ A}$ 電流源流出。
- 節點 1 與節點 2 之間：跨接 $2\text{ V}$ 獨立電壓源（正極接節點 2，負極接節點 1），頂部並聯一顆 $10\ \Omega$ 電阻。

### 步驟 1：列寫電壓源拘束方程式
觀察電壓源極性，正極在節點 2、負極在節點 1：
$$v_2 - v_1 = 2 \implies v_2 = v_1 + 2 \quad \text{--- (1)}$$

### 步驟 2：對超節點 1-2 列寫廣義 KCL
將節點 1、節點 2、中間電壓源與頂部 $10\ \Omega$ 電阻一同圈入超節點。觀察穿過邊界的外部電流：
- 左側：$2\text{ A}$ 流入
- 節點 1 下方：$\frac{v_1 - 0}{2}$ 流出
- 節點 2 下方：$\frac{v_2 - 0}{4}$ 流出
- 右側：$7\text{ A}$ 流出

列寫「流入 = 流出」：
$$2 = \frac{v_1}{2} + \frac{v_2}{4} + 7$$
整理得：
$$\frac{v_1}{2} + \frac{v_2}{4} = -5 \implies 2v_1 + v_2 = -20 \quad \text{--- (2)}$$

::: info 注意
頂部的 $10\ \Omega$ 電阻兩端均在超節點內部，其內部電流 $\frac{v_2 - v_1}{10}$ 在超節點封閉面內直接抵消，**絕對不能寫入邊界 KCL**！
:::

### 步驟 3：聯立求解
將式 (1) $v_2 = v_1 + 2$ 代入式 (2)：
$$2v_1 + (v_1 + 2) = -20 \implies 3v_1 = -22 \implies v_1 = -\frac{22}{3}\text{ V} \approx -7.333\text{ V}$$

代回求 $v_2$：
$$v_2 = -\frac{22}{3} + 2 = -\frac{16}{3}\text{ V} \approx -5.333\text{ V}$$

## 五、 觀念檢索挑戰 (Concept Check)

::: details 📝 題目 1：為什麼兩非參考節點間的電壓源不能直接列傳統 KCL？
**問題**：在節點分析中，為什麼兩非參考節點間的電壓源不能直接對個別節點列寫傳統 KCL？

**答案與解析**：
因為**理想電壓源內部的電流大小完全未知，無法用歐姆定律表達**。理想電壓源內阻為零，直接列式會引入額外未知變數 $i_v$。透過將其包絡為超節點，可使內部電流隱形。
:::

::: details 📝 題目 2：超節點方程式維度
**問題**：一個包含 $N$ 個非參考節點與 $k$ 個跨接在非參考節點間電壓源的電路，在超節點法中如何構成完整的方程組？

**答案與解析**：
共有 **$(N - k)$ 條超節點 KCL** 與 **$k$ 條電壓源拘束方程式**，總計 $(N-k)+k = N$ 條線性獨立方程式，剛好求解 $N$ 個未知節點電壓。
:::
