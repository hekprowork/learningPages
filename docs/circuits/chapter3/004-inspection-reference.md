# 觀察法分析速查手冊 (Inspection Analysis Cheatsheet)

本手冊摘錄自 Alexander & Sadiku Chapter 3，提供節點與網孔觀察法的矩陣公式快速查閱。

---

## 1. 節點觀察法 (Nodal Analysis by Inspection)

適用於**僅含電阻（電導）與獨立電流源**的電路。

**標準矩陣形式**：
$$ \mathbf{G} \mathbf{v} = \mathbf{i} $$

| 矩陣元素 | 定義與物理意義 | 符號慣例 |
| :--- | :--- | :--- |
| **主對角項** $G_{kk}$ | **自我電導 (Self-Conductance)** | 連接至節點 $k$ 的所有分支電導總和，**恆為正 (+)**。 |
| **非對角項** $G_{kj}$ | **互電導 (Mutual Conductance)** | 節點 $k$ 與 $j$ 之間直接連接的電導總和的**負值**。矩陣必對稱 ($G_{kj} = G_{jk}$)。 |
| **變數向量** $v_k$ | **節點電壓** | 非參考節點相對於接地的未知電壓。 |
| **常數向量** $i_k$ | **輸入電流源** | 注入節點 $k$ 的獨立電流源代數和。**流入為正 (+)，流出為負 (-)**。 |

---

## 2. 網孔觀察法 (Mesh Analysis by Inspection)

適用於**僅含電阻與獨立電壓源**的**平面電路**（且所有網孔電流方向皆規定為**順時針**）。

**標準矩陣形式**：
$$ \mathbf{R} \mathbf{i} = \mathbf{v} $$

| 矩陣元素 | 定義與物理意義 | 符號慣例 |
| :--- | :--- | :--- |
| **主對角項** $R_{kk}$ | **自我電阻 (Self-Resistance)** | 環繞網孔 $k$ 的所有分支電阻總和，**恆為正 (+)**。 |
| **非對角項** $R_{kj}$ | **互電阻 (Mutual Resistance)** | 網孔 $k$ 與 $j$ 所共用分支電阻總和的**負值**。矩陣必對稱 ($R_{kj} = R_{jk}$)。 |
| **變數向量** $i_k$ | **網孔電流** | 假定為順時針方向的未知網孔電流。 |
| **常數向量** $v_k$ | **輸入電壓源** | 網孔 $k$ 順時針繞行時遭遇的獨立電壓源代數和。**電壓升為正 (+)，電壓降為負 (-)**。 |

---

## 3. 防呆與除錯檢核表 (Pre-flight Checklist)

- [ ] **是否含有相依源？**  
  $\rightarrow$ **不能直接用**觀察法。相依源的變數移項會破壞對角對稱性。
- [ ] **節點法遇到獨立電壓源？**  
  $\rightarrow$ 需做「電源轉換 (Source Transformation)」變為電流源，或改用「超節點 (Supernode)」。
- [ ] **網孔法遇到獨立電流源？**  
  $\rightarrow$ 需做「電源轉換」變為電壓源，或改用「超網孔 (Supermesh)」。
- [ ] **網孔法方向設定是否一致？**  
  $\rightarrow$ 必須全部規定為順時針 (Clockwise) 才能保證非對角項恆負。
- [ ] **是否為非平面電路 (Nonplanar)？**  
  $\rightarrow$ 不能畫出不交叉的網孔，因此**無法使用網孔法**，必須改用節點法。
