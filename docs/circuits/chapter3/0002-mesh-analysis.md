# Lesson 0003: 網孔分析法 (Mesh Analysis) 與超網孔 (Supermesh) 的原理與實戰破解

> 掌握平面電路中迴路分析的核心利器：從標準 KVL 網孔方程到電流源共用支路的超網孔突破

## 🎯 本單元目標

在學習過以 KCL 為基石的**節點電壓法 (Nodal Analysis)** 後，本單元將建立其對偶的核心分析技術——**網孔電流法 (Mesh Current Analysis)**。

網孔分析以克希荷夫電壓定律 (KVL) 為出發點，透過引入「網孔電流」此一虛擬變數，天然滿足了所有節點的 KCL，將複雜電路的求解維度大幅降至獨立網孔數量。

然而，當電路中出現**「跨接在兩個網孔之間的電流源」**時，標準 KVL 會遇到無法計算端電壓的困境。此時，**超網孔 (Supermesh)** 技術將成為解題的核心殺手鐧。

讀完本課後，你將能夠：
- 深刻理解平面電路 (Planar Circuit) 的幾何定義與網孔 (Mesh) 的拓撲本質。
- 熟練運用標準網孔分析 4 步演算法列寫 KVL 方程式與阻抗矩陣。
- 掌握電流源的兩大處理情境，精通「超網孔 KVL + 電流源拘束方程式」雙核心架構。
- 融會貫通受控源控制量代換，並具備在節點分析與網孔分析間做出最佳戰術決策的能力。

## 一、 第一原理：為什麼需要網孔分析？

### 1. 物理對偶性：KCL 與 KVL 的鏡像對稱
電路學中存在優美的對偶原理 (Duality Principle)：
- **節點電壓法**：以**節點電壓**為未知數，對每個獨立節點列寫 **KCL**（$\sum i = 0$）。
- **網孔電流法**：以**網孔電流**為未知數，對每個獨立網孔列寫 **KVL**（$\sum v = 0$）。

### 2. 迴路 (Loop) 與網孔 (Mesh) 的嚴謹區分
在深入演算法前，必須釐清兩者幾何差異：
- **迴路 (Loop)**：電路中任何不重複經過同一節點的閉合路徑。
- **網孔 (Mesh)**：**內部不包含任何其他支路的最小封閉迴路**。

::: tip 💡 幾何直覺：窗格比喻 (Window Pane Analogy)
想像一扇由許多木框隔開的窗戶：
- 整扇窗戶外框是一個「迴路」，但不是「網孔」。
- 每一個單獨的小玻璃格，才是「**網孔 (Mesh)**」。
- 網孔分析**僅適用於平面電路 (Planar Circuits)**（即可以在平面上繪製且導線無立體交叉的電路）。
:::

```
┌───────┬───────┐
│       │       │
│ 網孔1 │ 網孔2 │  <── 網孔1 與 網孔2 是基本網孔
│ (i₁)  │ (i₂)  │      外圍大框是迴路 (Loop)，但不是網孔
└───────┴───────┘
```

### 3. 網孔電流 (Mesh Current) 的虛擬本質與守恆性
我們在每個網孔內部假設一個閉合流動的電流（通常約定為順時針方向）：
- 網孔電流 $i_1, i_2$ 是為了數學簡化而定義的**虛擬電流 (Fictitious Currents)**。
- **天然滿足 KCL**：由於每個網孔電流都是封閉環流，流進任何節點的量必定等於流出該節點的量，因此**節點 KCL 自動恆等成立**！
- **實際支路電流的還原**：
  - 僅屬於單一網孔的邊界支路：支路電流即為該網孔電流。
  - 由兩個網孔共用的中間支路：支路電流為兩相鄰網孔電流的代數差（如 $I_{\text{共用}} = i_1 - i_2$）。

## 二、 標準網孔分析法 (Standard Mesh Analysis)：4 步標準演算法

對於僅包含電阻與獨立電壓源的平面電路，標準求解步驟如下：

### 步驟 1 · 標定網孔電流
為電路中的 $M$ 個網孔分別指派順時針方向的網孔電流 $i_1, i_2, \dots, i_M$。

### 步驟 2 · 逐一對各網孔列寫 KVL
沿著網孔電流的順時針方向繞行一週，列寫「電壓升 = 電壓降」或 $\sum v = 0$：
- **自網孔電阻壓降**：流經自身電阻必產生正壓降 $+R \cdot i_k$。
- **共用電阻支路壓降**：若繞行網孔 1，共用電阻 $R$ 同時受網孔 2 電流 $i_2$ 影響。順著繞行方向，淨電流為 $(i_1 - i_2)$，故壓降為：
  $$v_R = R(i_1 - i_2)$$
- **電壓源電位變化**：
  - 繞行時若從「負極進入、正極流出」（電位上升），記為 $-V_s$（移至等號右邊為 $+V_s$）。
  - 若從「正極進入、負極流出」（電位下降），記為 $+V_s$（移至等號右邊為 $-V_s$）。

### 步驟 3 · 整理為矩陣方程式
將方程式化簡為標準矩陣形式：
$$\begin{bmatrix} R_{11} & R_{12} & \dots & R_{1M} \\ R_{21} & R_{22} & \dots & R_{2M} \\ \vdots & \vdots & \ddots & \vdots \\ R_{M1} & R_{M2} & \dots & R_{MM} \end{bmatrix} \begin{bmatrix} i_1 \\ i_2 \\ \vdots \\ i_M \end{bmatrix} = \begin{bmatrix} v_1 \\ v_2 \\ \vdots \\ v_M \end{bmatrix}$$

### 步驟 4 · 解方程組並計算目標量
利用高斯消去法或克拉瑪法則 (Cramer's Rule) 求解網孔電流，再由歐姆定律計算各元件電壓與功率。

## 三、 含有電流源的網孔分析：兩大情境分類

當電路中出現電流源時，網孔分析會遇到兩種截然不同的情況：

| 情境 | 電流源位置 | 特徵與影響 | 標準應對策略 |
| :--- | :--- | :--- | :--- |
| **情境 1** | 電流源僅存在於單一網孔的外側邊界 | 該網孔電流直接被電流源固定 | **直接定值 (Trivial)**<br>未知數減少 1 個，無需對該網孔列 KVL |
| **情境 2** | 電流源跨接在兩個相鄰網孔的共用支路 | 理想電流源端電壓 $v_s$ 未知，標準 KVL 無法列式 | **超網孔 (Supermesh)**<br>避開電流源繞大迴路列 KVL，補拘束式 |

::: warning 困境剖析：為什麼共用電流源會讓 KVL「卡住」？
理想電流源的內阻為無窮大（$\infty$）。它可以提供精確的恆定電流，但**其兩端的端電壓 $v_s$ 完全由外部電路決定**，無法透過歐姆定律（$v = R \cdot i$）表達！

若硬要對包含該電流源的網孔列寫 KVL，方程式中會多出一個未知電壓變數 $v_s$。若有 $k$ 個電流源，就會多出 $k$ 個未知電壓，方程式組無法閉合求解。
:::

## 四、 什麼是「超網孔 (Supermesh)」？

**破局思維**：既然理想電流源內部的端電壓未知，我們在繞行 KVL 時**直接繞過它，不走該支路**！

### 1. 超網孔的定義
將**共用電流源（無論是獨立電流源還是相依電流源）及其串聯的所有元件暫時移開（視為開路 Open Circuit）**，由原先的兩個網孔合併而成的一個擴大閉合迴路，稱為**超網孔 (Supermesh)**。

```
       原電路結構                         形成超網孔
┌─────────┬─────────┐             ┌─────────────────┐
│         │         │             │                 │
│  網孔 1  │ (↑) Is  │  網孔 2     │    大迴路 KVL     │
│  (i₁)   │ 共用源   │  (i₂)  ===> │    (內部 Is 隱形) │
│         │         │             │                 │
└─────────┴─────────┘             └─────────────────┘
```

### 2. 超網孔的兩大核心特性
1. **內部端電壓隱形**：由於超網孔路徑避開了電流源支路，理想電流源兩端未知的電壓降 $v_s$ **完全不會出現在 KVL 方程式中**。
2. **串聯元件一同略過**：任何與共用電流源直接串聯的電阻，其電流由該電流源唯一決定，在列寫超網孔大迴路 KVL 時**一併略過**。

### 3. 解題核心：超網孔的兩道黃金方程式

合併成超網孔後，方程式系統如何閉合？答案就在電流源本身提供的約束：

#### ① 超網孔 KVL 方程式 (Supermesh KVL)
沿著超網孔的外圍閉合邊界繞行一週列寫 KVL。
> **極重要提醒**：繞行超網孔時，流經各電阻的電流依然必須**使用各電阻所屬的原網孔電流**！切勿將超網孔誤認為單一電流。

#### ② 電流源拘束方程式 (Constraint Equation)
觀察共用支路上電流源的箭頭方向，由相鄰兩網孔電流之代數差直接列出：
$$i_{\text{同向}} - i_{\text{反向}} = I_s \quad (\text{或相依源 } \alpha I_o)$$

::: tip 💡 方程式維度不變性定理
設平面電路有 $M$ 個網孔，其中包含 $k$ 個相鄰網孔共用的電流源：
$$\text{超網孔 KVL 數量 } (M - k) + \text{電流源拘束式數量 } k = M \text{ 條獨立方程式}$$
獨立方程式總數依然恆等於未知網孔電流數量，系統嚴格封閉可解！
:::

## 五、 實戰拆解：3 大經典例題詳解

### 範例 1：標準雙網孔電路 (Example 3.5)

利用網孔分析法求解下圖電路中的各支路電流 $I_1, I_2, I_3$。

![Example 3.5 Circuit Diagram](../assets/images/ex_3_5_circuit.png)

#### 逐步解題流程：

1. **標定網孔電流**：
   - 左側網孔 1：順時針電流 $i_1$。
   - 右側網孔 2：順時針電流 $i_2$。

2. **對網孔 1 套用 KVL**（順時針繞行）：
   $$-15 + 5i_1 + 10(i_1 - i_2) + 10 = 0$$
   合併同類項：
   $$15i_1 - 10i_2 = 5 \implies 3i_1 - 2i_2 = 1 \quad \cdots (1)$$

3. **對網孔 2 套用 KVL**（順時針繞行）：
   $$-10 + 10(i_2 - i_1) + 6i_2 + 4i_2 = 0$$
   合併同類項：
   $$-10i_1 + 20i_2 = 10 \implies -i_1 + 2i_2 = 1 \quad \cdots (2)$$

4. **聯立求解網孔電流**：
   將 $(1)$ 式與 $(2)$ 式相加消去 $i_2$：
   $$(3i_1 - 2i_2) + (-i_1 + 2i_2) = 1 + 1 \implies 2i_1 = 2 \implies i_1 = 1\text{ A}$$
   代回 $(1)$ 式：
   $$3(1) - 2i_2 = 1 \implies 2i_2 = 2 \implies i_2 = 1\text{ A}$$

5. **還原各支路實際物理電流**：
   - 左側支路電流：$I_1 = i_1 = 1\text{ A}$
   - 右側支路電流：$I_2 = i_2 = 1\text{ A}$
   - 中間共用支路電流：$I_3 = i_1 - i_2 = 1 - 1 = 0\text{ A}$

### 範例 2：含受控電壓源之三網孔電路 (Example 3.6)

求解下圖電路中流經 $10\ \Omega$ 電阻的支路電流 $I_o$（電路包含受控電壓源 $4I_o$）。

![Example 3.6 Circuit Diagram](../assets/images/ex_3_6_circuit.png)

#### 逐步解題流程：

1. **標定網孔電流與相依源控制變數**：
   - 設定三個網孔電流分別為順時針方向的 $i_1, i_2, i_3$。
   - 觀察控制電流 $I_o$：流經 $10\ \Omega$ 電阻（由上往下），為網孔 1 與網孔 2 的共用支路：
     $$I_o = i_1 - i_2$$
   - 相依電壓源大小即為：$4I_o = 4(i_1 - i_2)$。

2. **對網孔 1 列 KVL**：
   $$-24 + 10(i_1 - i_2) + 12(i_1 - i_3) = 0 \implies 22i_1 - 10i_2 - 12i_3 = 24$$
   同除以 2：
   $$11i_1 - 5i_2 - 6i_3 = 12 \quad \cdots (1)$$

3. **對網孔 2 列 KVL**：
   $$24i_2 + 4(i_2 - i_3) + 10(i_2 - i_1) = 0 \implies -10i_1 + 38i_2 - 4i_3 = 0$$
   同除以 2：
   $$-5i_1 + 19i_2 - 2i_3 = 0 \quad \cdots (2)$$

4. **對網孔 3 列 KVL（含受控電壓源）**：
   $$4(i_3 - i_2) + 4I_o + 12(i_3 - i_1) = 0$$
   代入控制變數 $I_o = i_1 - i_2$：
   $$4(i_3 - i_2) + 4(i_1 - i_2) + 12(i_3 - i_1) = 0$$
   $$-8i_1 - 8i_2 + 16i_3 = 0 \implies -i_1 - i_2 + 2i_3 = 0 \quad \cdots (3)$$

5. **克拉瑪法則 (Cramer's Rule) 矩陣求解**：
   $$\begin{bmatrix} 11 & -5 & -6 \\ -5 & 19 & -2 \\ -1 & -1 & 2 \end{bmatrix} \begin{bmatrix} i_1 \\ i_2 \\ i_3 \end{bmatrix} = \begin{bmatrix} 12 \\ 0 \\ 0 \end{bmatrix}$$
   主行列式 $\Delta = 192$；代換第一行 $\Delta_1 = 432$，代換第二行 $\Delta_2 = 144$：
   $$i_1 = \frac{432}{192} = 2.25\text{ A}, \quad i_2 = \frac{144}{192} = 0.75\text{ A}$$
   計算目標支路電流：
   $$I_o = i_1 - i_2 = 2.25\text{ A} - 0.75\text{ A} = 1.5\text{ A}$$

### 範例 3：複合超網孔與受控電流源電路 (Example 3.7)

求解下圖電路中的各網孔電流 $i_1, i_2, i_3, i_4$（網孔 1, 2, 3 共用獨立電流源 $5\text{ A}$ 與相依電流源 $3I_o$）。

![Example 3.7 Circuit Diagram](../assets/images/ex_3_7_circuit.png)
![Example 3.7 Supermesh Concept Diagram](../assets/images/ex_3_7_supermesh.png)

#### 逐步解題流程：

1. **識別超網孔 (Supermesh 1-2-3)**：
   - 網孔 1 與 2 之間夾有 $5\text{ A}$ 獨立電流源。
   - 網孔 2 與 3 之間夾有 $3I_o$ 相依電流源。
   - 將兩電流源支路移除，網孔 1、2、3 合併成一個大型超網孔（如紅色虛線所示）。

2. **建立電流源拘束方程式 (Constraint Equations)**：
   - **獨立電流源 $5\text{ A}$**（向右流動，節點 P 之 KCL）：
     $$i_2 - i_1 = 5 \implies i_1 = i_2 - 5 \quad \cdots (1)$$
   - **相依電流源 $3I_o$**（向下流動，節點 Q 之 KCL）：
     $$i_2 - i_3 = 3I_o \quad \cdots (2)$$
   - 觀察控制電流 $I_o$：流經最右側 $2\ \Omega$ 支路（向上流動），與順時針網孔電流 $i_4$ 反向：
     $$I_o = -i_4$$
     代入 $(2)$ 式得：
     $$i_2 - i_3 = 3(-i_4) = -3i_4 \implies i_2 = i_3 - 3i_4 \quad \cdots (3)$$
     代回 $(1)$ 式可得：
     $$i_1 = i_3 - 3i_4 - 5$$

3. **對大型超網孔 1-2-3 繞行列 KVL**：
   沿著外圍輪廓順時針繞行：
   $$6i_2 + 2i_1 + 4i_3 + 8(i_3 - i_4) = 0$$
   整理化簡：
   $$2i_1 + 6i_2 + 12i_3 - 8i_4 = 0 \implies i_1 + 3i_2 + 6i_3 - 4i_4 = 0 \quad \cdots (4)$$

4. **對獨立的網孔 4 列 KVL**：
   $$2i_4 + 10 + 8(i_4 - i_3) = 0 \implies -8i_3 + 10i_4 = -10 \implies -4i_3 + 5i_4 = -5 \quad \cdots (5)$$

5. **聯立消去求解**：
   將 $(1)$ 式與 $(3)$ 式代入 $(4)$ 式，得到僅含 $i_3, i_4$ 的二元聯立方程：
   $$(i_3 - 3i_4 - 5) + 3(i_3 - 3i_4) + 6i_3 - 4i_4 = 0 \implies 10i_3 - 16i_4 = 5 \quad \cdots (6)$$
   聯立 $(5)$ 式與 $(6)$ 式：
   $$\begin{cases} 10i_3 - 16i_4 = 5 \\ -4i_3 + 5i_4 = -5 \end{cases}$$
   解得：
   $$i_4 = \frac{15}{7}\text{ A} \approx 2.143\text{ A}, \quad i_3 = \frac{55}{14}\text{ A} \approx 3.929\text{ A}$$
   代回 $(3)$ 式與 $(1)$ 式：
   $$i_2 = i_3 - 3i_4 = \frac{55}{14} - 3\left(\frac{15}{7}\right) = -2.5\text{ A}$$
   $$i_1 = i_2 - 5 = -2.5 - 5 = -7.5\text{ A}$$
   *(精準解析詳見題庫 Chapter 3 Practice Problem)*

## 六、 觀察法矩陣阻抗法 (Inspection Method for Mesh Analysis)

對於**僅含線性電阻與獨立電壓源**的平面電路，可以直接以「觀察法」寫出電阻矩陣方程式 $[R][i] = [v]$：

$$\begin{bmatrix} R_{11} & R_{12} & \dots & R_{1M} \\ R_{21} & R_{22} & \dots & R_{2M} \\ \vdots & \vdots & \ddots & \vdots \\ R_{M1} & R_{M2} & \dots & R_{MM} \end{bmatrix} \begin{bmatrix} i_1 \\ i_2 \\ \vdots \\ i_M \end{bmatrix} = \begin{bmatrix} v_1 \\ v_2 \\ \vdots \\ v_M \end{bmatrix}$$

- **主對角線項（自電阻 $R_{kk}$）**：網孔 $k$ 內部**所有電阻的算術總和**（恆為正值）。
- **非對角線項（互電阻 $R_{jk} = R_{kj}$）**：網孔 $j$ 與網孔 $k$ **共用支路之電阻總和取負值**（若無共用支路則為 0）。
- **激勵電壓項 ($v_k$)**：沿網孔 $k$ 順時針繞行方向，所有獨立電壓源的**升壓代數和**（由負入正為正，由正入負為負）。

::: tip 💡 觀察法對偶性記憶表
| 特性 | 節點分析矩陣 $[G][v] = [i]$ | 網孔分析矩陣 $[R][i] = [v]$ |
| :--- | :--- | :--- |
| **主對角項** | 自電導 $G_{kk}$（接於節點 $k$ 的電導和，恆正） | 自電阻 $R_{kk}$（網孔 $k$ 的電阻和，恆正） |
| **非對角項** | 互電導 $G_{kj}$（節點 $j, k$ 間電導和之負值） | 互電阻 $R_{kj}$（網孔 $j, k$ 共用電阻和之負值） |
| **激勵來源** | 流入節點之獨立電流源代數和 | 順時針繞行之獨立電壓源升壓代數和 |
:::

## 七、 戰術抉擇：節點分析法 vs 網孔分析法 (Nodal vs Mesh)

面對一張未知電路，究竟該選用「節點分析」還是「網孔分析」？可遵循下列 3 大決策維度：

```
                        [開始分析電路]
                              │
               ┌──────────────┴──────────────┐
               ▼                             ▼
        [非平面電路？]                 [平面電路]
         (導線立體交叉)                       │
               │               ┌─────────────┴─────────────┐
        [強制選用節點法]        ▼                           ▼
                        [非參考節點數 (N-1)]        [獨立網孔數 (M)]
                               │                           │
                               └─────────────┬─────────────┘
                                             ▼
                               [比較方程式數量維度]
                               (N-1 < M ──> 選用節點法)
                               (M < N-1 ──> 選用網孔法)
                                             │
                                             ▼
                               [檢查電源類型權重]
                               (電壓源多 ──> 偏好網孔法 / 超節點)
                               (電流源多 ──> 偏好節點法 / 超網孔)
```

### 決策對照表

| 評估維度 | 節點電壓法 (Nodal Analysis) | 網孔電流法 (Mesh Analysis) |
| :--- | :--- | :--- |
| **適用範圍** | 任何電路（平面與非平面皆可） | **僅限平面電路 (Planar Circuits)** |
| **未知數數量** | $N - 1$（$N$ 為總節點數） | $M = B - N + 1$（$B$ 為總支路數） |
| **偏好電源類型** | 電流源多時極其便利（電壓源需超節點） | 電壓源多時極其便利（電流源需超網孔） |
| **最適合目標變數** | 欲求多處節點對地電壓、運算放大器電路 | 欲求迴路電流、電晶體基極/集極迴路分析 |

## 八、 觀念檢索挑戰 (Concept Check)

::: details 📝 題目 1：為什麼非平面電路無法使用網孔分析法？
**問題**：在非平面電路（Nonplanar Circuit）中，為什麼無法直接應用網孔分析法？

**答案與解析**：
因為非平面電路的導線存在立體交叉，無法在二維平面上定義出「內部不包含任何其他支路」的最小幾何網孔 (Mesh)。若要對非平面電路進行迴路分析，必須選取樹 (Tree) 與連支 (Links) 來建立基底迴路，使用更一般化的**迴路分析法 (General Loop Analysis)**。
:::

::: details 📝 題目 2：超網孔繞行時，共用電阻的電流代號該怎麼寫？
**問題**：在列寫超網孔 KVL 時，某顆電阻位於原本網孔 1 的外側路徑上，此時該電阻的壓降應該用哪個電流表示？

**答案與解析**：
必須嚴格使用該電阻原來所屬的網孔電流 $i_1$！**超網孔只是 KVL 的繞行閉合路徑**，電路中各支路的實體電流依然是由原本指派的網孔電流（$i_1, i_2$ 等）所決定，切勿自己發明一個「超網孔電流」代入。
:::

::: details 📝 題目 3：與共用電流源串聯的電阻，會影響網孔電流的解嗎？
**問題**：若在相鄰兩網孔共用的電流源支路上串聯了一顆電阻 $R_s$，這顆電阻會影響電路的網孔電流解嗎？

**答案與解析**：
**不會！** 因為在形成超網孔時，電流源與其串聯的支路被整體視為開路移開，超網孔 KVL 不經過該支路；而在電流源拘束式中，電流差值只由電流源強度決定。因此 $R_s$ 完全不會改變任何網孔電流的大小（但它會改變電流源兩端的端電壓）。
:::
