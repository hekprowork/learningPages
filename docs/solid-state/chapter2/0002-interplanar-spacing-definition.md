# 0002: 密勒指數晶面求法與面間距幾何

> 晶面間距的精確幾何定義、向量推導與布拉格繞射物理連結

## 🎯 學習紀錄核心重點

學習者掌握了晶面指數的求法，並深入探討「面間距 (Interplanar Spacing)」的精確幾何與物理定義。理解「一組平行晶面族的法向垂直間距」是後續布拉格繞射 (Bragg Diffraction) 與 X 光繞射 (XRD) 晶格測量的基石。

---

## 一、 面間距 $d_{hkl}$ 的幾何定義

在晶體幾何中，密勒指數 $(hkl)$ 定義的並非單一孤立平面，而是**一整組平行且等間距的平面族**。

- **定義**：該平面族中任意兩相鄰相鄰平行平面之間的**垂直距離（法向距離）**，即為面間距 $d_{hkl}$。
- 原點所在的平面方程為：
  $$hx + ky + lz = 0$$
- 離原點最近的第一個平面的方程為：
  $$hx + ky + lz = a$$

---

## 二、 嚴密數學推導：立方晶系公式

在邊長為 $a$ 的正交立方座標系中，平面方程為：

$$\frac{x}{a/h} + \frac{y}{a/k} + \frac{z}{a/l} = 1 \iff hx + ky + lz = a$$

由三維解析幾何，點 $(x_0, y_0, z_0) = (0, 0, 0)$ 到平面 $Ax + By + Cz - D = 0$ 的垂直距離公式為：

$$d = \frac{|Ax_0 + By_0 + Cz_0 - D|}{\sqrt{A^2 + B^2 + C^2}}$$

將 $A=h, B=k, C=l, D=a$ 代入原點距離公式：

$$d_{hkl} = \frac{|0 + 0 + 0 - a|}{\sqrt{h^2 + k^2 + l^2}} = \frac{a}{\sqrt{h^2 + k^2 + l^2}}$$

::: tip 物理直觀
1. 指數平方和 $h^2 + k^2 + l^2$ 越大，面間距 $d_{hkl}$ 越小。
2. 面間距越小，代表單位體積內該組平面的層數越密集。
:::

---

## 三、 與 X 光繞射 (XRD) 的物理關聯：布拉格定律

當波長為 $\lambda$ 的 X 射線以入射角 $\theta$ 入射晶體時，相鄰兩平行晶面的光程差為：

$$\Delta = 2 d_{hkl} \sin\theta$$

產生建設性干涉（繞射峰）的條件即為**布拉格定律 (Bragg's Law)**：

$$2 d_{hkl} \sin\theta = n\lambda \quad (n \in \mathbb{N})$$

藉由實驗量測各繞射峰的掠射角 $\theta$，配合布拉格定律即可反推出面間距 $d_{hkl}$，進而精確測定半導體材料的晶格常數 $a$ 與應力應變狀態。
