# 0003: 塊狀晶體生長與偏析效應

> 矽原料純化、CZ/LEC 單晶長晶技術、常規凝固偏析方程式與 Example 1–4 計算思維總結

## 🎯 學習紀錄核心重點

學習者進入固態電子元件物理的基石章節「塊狀晶體生長 (Bulk Crystal Growth)」，系統化掌握了：

1. **原料提純路徑**：
   - 冶金級矽 (MGS, ~98%) $\to$ 三氯氫矽分餾 ($\text{SiHCl}_3$, bp $32^\circ\text{C}$) $\to$ 電子級矽 (EGS, 西門子法 $9\text{N}\sim 11\text{N}$ 高純多晶)。
2. **單晶長晶法**：
   - 柴氏長晶法 (CZ) 提拉單晶錠、液封柴氏法 (LEC) 藉由熔融 $\text{B}_2\text{O}_3$ 封印高揮發性 V 族元素 ($\text{GaAs}/\text{InP}$)。
3. **偏析/分佈係數 ($k_d = C_S / C_L$)**：
   - 因多數半導體雜質 $k_d < 1$，凝固過程固相對雜質產生排斥，導致剩餘熔湯雜質富集，晶棒尾端雜質濃度依常規凝固方程式 $C_S(g) = k_d C_0 (1-g)^{k_d - 1}$ 顯著攀升。
4. **例題計算與晶圓加工**：
   - 掌握 Example 1–4 摻雜質量計算 SOP，以及線鋸切割與化學機械研磨 (CMP) 奈米鏡面拋光原理。

## 一、 關鍵公式與物理意義精要

### 1. 偏析分佈係數 (Segregation Coefficient)
$$k_d = \frac{C_S}{C_L}$$
- 當 $k_d < 1$ 時，固相雜質濃度低於液相，雜質被「排斥」至熔湯中，使液相濃度隨凝固持續提高。

### 2. 常規凝固方程式 (Normal Freezing Equation)
$$C_S(g) = k_d C_0 (1 - g)^{k_d - 1}$$
- $g$：固化比例（從晶棒頭部 $g=0$ 到尾部 $g \to 1$）。
- $C_0$：初始熔湯總雜質濃度。
- 若 $k_d = 0.3$（如 $\text{As}$ 在 $\text{Si}$ 中），頭部固相濃度為 $0.3 C_0$，而到了 $g=0.9$ 時，濃度攀升至：
  $$C_S(0.9) = 0.3 C_0 (0.1)^{-0.7} \approx 1.5 C_0 \quad (\text{升高了 5 倍！})$$

## 二、 實務製程與工程考量

1. **長晶熱場與轉速控制**：
   - 柴氏法中晶種與坩堝反向旋轉（$\omega_1, \omega_2$），目的是維持對稱熱場、強制熔湯對流並確保摻雜徑向均勻。
2. **氧與碳污染管理**：
   - 石英坩堝高溫下會溶入微量 $\text{SiO}_2$，在矽中引入氧雜質（約 $10^{18}\text{ cm}^{-3}$）。適量沈澱氧能吸附過渡金屬，產生**內部吸雜 (Internal Gettering)** 的益處。
3. **CMP 研磨之雙重機制**：
   - 機械拋光不能單獨使用，否則會產生大量晶格殘留應力與差排；結合化學水解形成軟質水合氧化層，再以膠體石英微粒磨除，是現代次奈米製程平坦化的唯一解法。
