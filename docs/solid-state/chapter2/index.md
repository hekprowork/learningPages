# Chapter 2：原子與電子 (Atoms and Electrons)

> 從光電效應與原子光譜出發，建立波粒二象性、波耳模型、量子力學與原子軌域的完整學習路線。

本章依本地教材原生 Chapter 2 的順序編排。每一頁都將課文重整為「物理問題 → 數學模型 → 例題 → 自我檢核」，方便循序閱讀，也可單獨查閱。

## 本章學習目標

完成本章後，你應能：

- 說明光電效應與原子線光譜為何無法只靠古典物理完整解釋；
- 使用光子能量、波耳能階與 Rydberg 公式計算光譜；
- 解釋波函數、機率密度、不確定原理與薛丁格方程式的物理意義；
- 推導一維無限深位能井的本徵函數與離散能量；
- 判斷量子穿隧率如何受障壁高度、寬度與粒子質量影響；
- 使用四個量子數描述原子軌域，並由電子組態連接週期表與半導體鍵結。
