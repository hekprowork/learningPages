# 0006：週期晶體中的波與布里淵區

> 教材 Chapter 1，§1.5（PDF 閱讀頁 46–48）。此處是一維模型，建立後續聲子、物質波與 $E$–$k$ 圖的語言。

## 1. 從波長到波向量

令波形為 $u(x,t)=A\cos(kx-\omega t)$，則 $k=2\pi/\lambda$、$\omega=2\pi\nu$。單一正弦波的**相速度**為 $v_{\rm p}=\omega/k$；由鄰近波數疊加而成的波包，其**群速度**為 $v_{\rm g}=d\omega/dk$。兩者在有色散的晶體中不必相同。對電子物質波，能量 $E=\hbar\omega$，所以 $v_{\rm g}=(1/\hbar)\,dE/dk$。

## 2. 為何波數只需看第一布里淵區？

設一維原子位置為 $x_n=na$。波數 $k$ 與 $k+2\pi/a$ 在各原子位置的相位差為 $2\pi n$，因此**取樣在晶格點上的圖樣相同**。波數可選在第一布里淵區 $-\pi/a\le k<\pi/a$；區邊對應最短可區分的晶格取樣波長 $2a$。

這個結論是**離散晶格的波數等價性**，不表示連續空間中小於 $2a$ 的所有波都無法存在。

## 3. 週期邊界條件

對長度 $L=Na$ 的有限模型，取 $u(x+L)=u(x)$ 可把數學上首尾接合。若 $u\propto e^{ikx}$，則 $e^{ikL}=1$，所以

$$k_m=\frac{2\pi m}{L},\qquad m\in\mathbb Z.$$

在第一布里淵區只保留 $N$ 個不同的 $k$ 值。原子位移形成的集體振動可量子化為**聲子**；電子在週期位能中的波則導向第 3 章的[能帶](/solid-state/chapter3/0001-energy-bands)。兩者是不同物理對象，雖共用波向量表示法。
