## 一、 符號系統：四種括號的嚴格界定

在固態物理中，不同括號具有完全不同的物理定義：

| 符號語法 | 物理意義 | 直觀範例 |
| :--- | :--- | :--- |
| **`[h k l]`** | **特定晶向向量** | $[100]$ 表示沿 $x$ 軸方向的單位向量。 |
| **`⟨h k l⟩`** | **等效晶向家族** | $\langle 100 \rangle$ 包含 $[100], [\bar{1}00], [010], [0\bar{1}0], [001], [00\bar{1}]$。 |
| **`(h k l)`** | **特定晶面** | $(100)$ 與 $x$ 軸交於 $1$，平行 $y, z$ 軸。 |
| **`{h k l}`** | **等效晶面家族** | $\{100\}$ 包含立方體 6 個外表面對應的所有面。 |

> 💡 **記憶口訣**：
> - **方方向**（`[ ]` 代表單一方向）、**圓面**（`( )` 代表單一平面）
> - **尖家族**（`⟨ ⟩` 方向家族）、**花家族**（`{ }` 面家族）
> - 負值標記在數字上方，如 $\bar{1}$ 讀作 "bar 1"。

## 二、 晶面指數 $(hkl)$ 的四步標準求法

::: tip 經典範例剖析
假設某晶面與座標軸的截距為：$x = 1a$，$y = 2a$，且與 $z$ 軸平行（截距為 $\infty$）。

1. **寫出截距**：$(1, 2, \infty)$
2. **取倒數**：$\left(\frac{1}{1}, \frac{1}{2}, \frac{1}{\infty}\right) = (1, \frac{1}{2}, 0)$
3. **通分化為最簡整數比**：同乘以 $2 \to (2, 1, 0)$
4. **加圓括號標記**：此晶面即為 **$(210)$** 面。
:::

---

## 三、 立方晶格的面間距幾何定理

相鄰兩組平行 $(hkl)$ 平面之間的垂直距離 $d_{hkl}$ 為：

$$d_{hkl} = \frac{a}{\sqrt{h^2 + k^2 + l^2}}$$

> 💡 **物理推論**：
> 指數平方和 $h^2+k^2+l^2$ 越大，晶面間距 $d$ 就越小，代表該晶面排列越密集（如 $(111)$ 的間距小於 $(100)$）。

## ⚔️ 隨堂實戰與觀念驗證

::: details 問題 1：某晶面與 $x$ 軸相交於 $1a$、與 $y$ 軸相交於 $3a$、與 $z$ 軸平行，其密勒指數為？
- **選項**：
  - A. (130)
  - **B. (310) (正確)**
  - C. (131)
  - D. (313)
- **解析**：
  截距為 $(1, 3, \infty)$ $\to$ 取倒數為 $(1/1, 1/3, 0)$ $\to$ 同乘以 3 化為最簡整數比為 **(310)**。
:::

::: details 問題 2：邊長為 $a$ 的立方晶格中，$(100)$ 面間距 $d_{100}$ 與 $(111)$ 面間距 $d_{111}$ 比較為何？
- **選項**：
  - **A. 間距 $d_{100} > d_{111}$ (正確)**
  - B. 間距 $d_{100} < d_{111}$
  - C. 兩者完全相同
- **解析**：
  $d_{100} = \frac{a}{\sqrt{1}} = a$，而 $d_{111} = \frac{a}{\sqrt{1+1+1}} = \frac{a}{\sqrt{3}} \approx 0.577a$，因此 $d_{100} > d_{111}$。
:::
