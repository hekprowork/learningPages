# 0005：磊晶生長、晶格匹配與缺陷

> 教材 Chapter 1，§1.4（PDF 閱讀頁 38–45）。塊狀單晶的製造見[前一課](/solid-state/chapter1/0003-bulk-crystal-growth)。

## 1. 磊晶與普通薄膜的差別

磊晶 (epitaxy) 是在單晶基板上生長**有固定晶向關係的單晶層**。塊狀長晶製造整支晶棒；磊晶在已做好的晶圓上控制薄層的材料、厚度與摻雜。化學氣相沉積 (CVD) 也能形成多晶或非晶層，因此 **CVD 產物不一定是磊晶層**。

同質磊晶的薄層與基板是同種材料；異質磊晶則不同，例如 $\mathrm{Al}_x\mathrm{Ga}_{1-x}\mathrm{As}$ 長在 GaAs 上。改變 $x$ 可調材料性質，但也須考慮晶格常數。

## 2. 晶格不匹配、應變與錯配差排

可用 $f=(a_{\rm layer}-a_{\rm sub})/a_{\rm sub}$ 表示未受應變材料相對基板的晶格不匹配率；題目若指定相反分母或符號，以題目定義為準。

- 若薄層很薄、失配小，可能順著基板的面內間距生長，形成**受應變的擬晶 (pseudomorphic) 層**。
- 厚度超過臨界值後，應變能可能由**錯配差排 (misfit dislocation)** 釋放。差排是晶格中原子排列不連續的線缺陷，會影響元件品質。
- 「晶格常數相近」與「材料完全相同」並非同義；近似匹配可讓不同能隙的材料堆疊成異質結構。

例：若 $a_{\rm sub}=5.65\,\text{Å}$、$a_{\rm layer}=5.76\,\text{Å}$，則 $f=0.11/5.65\approx1.95\%$。自由狀態下薄層晶格較大；若被迫配合較小的基板面內晶格，面內受到壓縮。

## 3. 三種生長方法

| 方法 | 原料到表面的方式 | 常見考點 |
| :--- | :--- | :--- |
| 氣相磊晶 (VPE) | 氣態前驅物在加熱基板附近反應或分解 | 可形成控制摻雜的單晶層 |
| 金屬有機氣相磊晶 (MOVPE/OMVPE) | 使用金屬有機前驅物等氣體 | 適合多層 III–V 化合物結構 |
| 分子束磊晶 (MBE) | 高真空中由蒸發源提供原子或分子束 | 快門可快速切換成分與摻雜，製作極薄層 |

## 4. 把第 1 章接到第 3 章

不同材料的薄層形成能帶邊緣差，使載子可能被限制在窄能隙層中；這就是[量子井](/solid-state/chapter3/0002-carriers-and-effective-mass)與第 2 章[位能井](/solid-state/chapter2/0007-potential-well)的聯繫。

::: details 自我檢核：為何不能只說「用 CVD 就一定能得到單晶磊晶」？
CVD 只描述材料由氣相沉積的途徑；基板、表面清潔度、溫度及生長條件若不合適，沉積層可能是多晶或非晶。
:::
