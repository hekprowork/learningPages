# 0004：半導體材料、晶格與晶胞

> 教材 Chapter 1，§1.1–1.2.2（PDF 閱讀頁 22–28）。本頁補足進入密勒指數前必須先會的材料分類與晶胞計數。

## 1. 哪些材料稱為半導體？

半導體的導電率介於典型金屬與絕緣體之間，且可藉**溫度、光照與雜質濃度**顯著改變。材料名稱不能單靠「導電率剛好在中間」死記；[能帶與載子](/solid-state/chapter3/0001-energy-bands)會解釋為何它可被調控。

| 類別 | 例子 | 晶體中的原子 |
| :--- | :--- | :--- |
| 元素半導體 | Si、Ge | 單一元素，常見鑽石結構 |
| III–V 化合物 | GaAs、GaN | 第 III 族與第 V 族組成 |
| II–VI 化合物 | ZnSe、CdS | 第 II 族與第 VI 族組成 |
| 合金 | $\mathrm{Al}_x\mathrm{Ga}_{1-x}\mathrm{As}$ | 在同一子晶格上改變組成 $x$ |

矽適合大規模積體電路；部分化合物適合發光或高速元件。材料用途仍要看能隙、是否直接能隙、遷移率及製程條件，不能只看族別。

## 2. 晶格、基底與晶體不是同一個詞

- **晶格 (lattice)**：以平移重複的數學位置集合。
- **基底 (basis)**：附在每一晶格點上的原子群。
- **晶體結構**：晶格加上基底。矽為 **FCC 晶格 + 兩原子基底**，不等於「只有 FCC 原子」。
- **原胞**：最小的平移重複體積；**傳統立方晶胞**：較大但便於看對稱性。FCC 傳統晶胞含 4 個晶格點，鑽石結構傳統晶胞含 8 個原子。

數原子時，只計晶胞所占份額：角落原子占 $1/8$，面心占 $1/2$，體心占 $1$。簡單立方 (SC)、體心立方 (BCC)、面心立方 (FCC) 的傳統晶胞分別含 $1,2,4$ 個晶格點。鑽石結構再乘兩原子基底，得 $8$ 個原子，詳見[密度推導](/solid-state/chapter1/0002-diamond-lattice-density)。

## 3. 晶面、晶向與幾何計算

立方晶格中，晶格常數為 $a$ 時，$[hkl]$ 方向與 $(hkl)$ 晶面垂直；**非立方晶格不能照搬**。兩晶向 $[h_1k_1l_1]$ 和 $[h_2k_2l_2]$ 的夾角為

$$
\cos\theta=
\frac{h_1h_2+k_1k_2+l_1l_2}
{\sqrt{h_1^2+k_1^2+l_1^2}\sqrt{h_2^2+k_2^2+l_2^2}}.
$$

例：$[100]$ 與 $[111]$ 的 $\cos\theta=1/\sqrt3$，故 $\theta\approx54.7^\circ$。晶面指數的截距法與面間距另見[密勒指數教學](/solid-state/chapter1/0001-miller-indices)。

## 自我檢核

::: details 為何「FCC 晶胞含 4 個晶格點」和「矽晶胞含 8 個原子」都正確？
矽的晶體結構有兩原子基底，每個 FCC 晶格點對應兩個 Si 原子，所以傳統晶胞共 $4\times2=8$ 個原子。兩句話計算的對象不同。
:::

::: details $[110]$ 與 $[1\bar10]$ 的夾角是多少？
內積 $1(1)+1(-1)+0(0)=0$，故夾角為 $90^\circ$。
:::
