密勒指數 (Miller Indices) 與晶格幾何速查表

固態電子學必備晶面、晶向與幾何關係壓縮綱要

一、 括號符號語義 (Notation Summary)

符號 英文名稱 物理意義 立方晶格範例與包含項目
[h k l] Direction 特定的晶格方向（向量） \([100]\)：沿 \(x\) 軸正向的單位向量
⟨h k l⟩ Family of Directions 晶體對稱性下等效的所有晶向集合 \(\langle 100 \rangle = [100], [\bar{1}00], [010], [0\bar{1}0], [001], [00\bar{1}]\)
(h k l) Plane 一組特定的平行晶格平面 \((110)\)：截距為 \(1, 1, \infty\) 的平面
{h k l} Family of Planes 晶體對稱性下等效的所有晶面集合 \(\{100\} = (100), (\bar{1}00), (010), (0\bar{1}0), (001), (00\bar{1})\)

💡 記憶口訣：方方向（[ ] 代表方向）、圓面（( ) 代表平面）；尖家族（⟨ ⟩ 方向家族）、花家族（{ } 面家族）。 負值標記在數字上方，如 \(\bar{1}\) 讀作 "bar 1"。

二、 晶面指數 \((hkl)\) 標準求法 SOP

  1. 定原點：選定座標軸。若平面恰好通過原點，平移原點至相鄰晶格點。
  2. 求截距 (Intercepts)：找出平面與 \(x, y, z\) 軸的截距，以晶格常數 \(a, b, c\) 為單位。平行軸之截距為 \(\infty\)。
  3. 取倒數 (Reciprocals)：將三軸截距取倒數，\(\frac{1}{\infty} \to 0\)。
  4. 化互質整數 (Reduce)：通分並同乘以最小公倍數，化為互質整數組 \((hkl)\)。

三、 立方晶格三大幾何公式

1. 晶面法向量定理：在立方系統中，晶面 \((hkl)\) 的垂直法向量，恰好就是同名晶向 \([hkl]\)。

2. 晶面間距公式 (Interplanar Spacing)：

$$d_{hkl} = \frac{a}{\sqrt{h^2 + k^2 + l^2}}$$

3. 兩晶向夾角公式 (Angle between Directions)：晶向 \([h_1 k_1 l_1]\) 與 \([h_2 k_2 l_2]\) 之夾角 \(\theta\)：

$$\cos\theta = \frac{h_1 h_2 + k_1 k_2 + l_1 l_2}{\sqrt{h_1^2 + k_1^2 + l_1^2}\sqrt{h_2^2 + k_2^2 + l_2^2}}$$
