# 002: 鑽石與閃鋅礦結構幾何速查表 (Diamond & Zincblende Reference)

> 半導體核心幾何常數、原子密度計算與最近鄰距離推導總整理

## 一、 鑽石結構幾何關鍵常數 (矽 $\text{Si}$ 範例)

| 物理量名稱 | 符號 / 理論公式 | 矽 ($\text{Si}$) 數值與單位 | 物理意義說明 |
| :--- | :--- | :--- | :--- |
| **晶格常數 (Lattice Constant)** | $a$ | $5.43\text{ \AA} = 5.43 \times 10^{-8}\text{ cm}$ | 傳統立方晶胞的單邊長度 |
| **晶胞內原子總數 (Atoms/Cell)** | $N_{\text{cell}} = 4 (\text{FCC}) + 4 (\text{內插}) = 8$ | **8 個原子 / 晶胞** | 1 個鑽石晶胞包含 8 個完整的矽原子 |
| **原子體密度 (Volume Density)** | $\rho_V = \frac{8}{a^3}$ | **$5.0 \times 10^{22}\text{ atoms/cm}^3$** | 固態半導體最常用的體原子濃度基準常數 |
| **最近鄰原子距離 (Nearest Neighbor)** | $d_{\text{NN}} = \frac{\sqrt{3}}{4}a$ | **$2.35\text{ \AA}$** | 共價鍵長度（體對角線長度的四分之一） |
| **配位數 (Coordination Number)** | $Z = 4$ | **4** | 每個原子被 4 個最近鄰原子以四面體共價鍵包圍 |

## 二、 矽三大晶面之「面原子密度」($\text{atoms/cm}^2$) 總結

| 晶面 $(hkl)$ | 面截面等效原子數計算 | 面密度理論公式 | 矽之數值 ($\text{atoms/cm}^2$) |
| :--- | :--- | :--- | :--- |
| **(100) 面** | 4 角落 ($\frac{1}{4} \times 4$) + 1 面心 ($1$) = **2 個** | $\frac{2}{a^2}$ | $6.78 \times 10^{14}$ |
| **(110) 面** | 4 角落 ($\frac{1}{4} \times 4$) + 2 面心 ($\frac{1}{2} \times 2$) + 2 內部原子 ($2$) = **4 個** | $\frac{4}{\sqrt{2}a^2} = \frac{2\sqrt{2}}{a^2}$ | $9.59 \times 10^{14}$ |
| **(111) 面** | 等邊三角形截面等效包含 **2 個原子**（密排面） | $\frac{4}{\sqrt{3}a^2}$ | **$1.56 \times 10^{15}$**（密度最高） |

::: tip 製程重要直覺
- **$(111)$ 面**：原子面密度最高，鍵結最密，因此化學蝕刻速率最慢；
- **$(100)$ 面**：表面懸鍵態 (Dangling Bonds) 較少，界面能態密度低，廣泛用於現代 MOSFET 通道表面。
:::
