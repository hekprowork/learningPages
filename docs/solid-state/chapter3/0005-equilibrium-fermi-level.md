# 0005：熱平衡時費米能階為何必須一致？

> 教材 Chapter 3，§3.5（PDF 閱讀頁 132–133）。這是後續分析接面能帶圖的邊界條件。

## 1. 接觸後會發生什麼？

兩塊可交換電子的材料接觸前，若電子化學位能不同，載子會重新分布。分布產生的內建電場使帶邊隨位置改變，直到**總的電子化學位能**在整個熱平衡系統相同。在能帶圖上，這個參照就是水平的平衡費米能階：

$$E_F(x)=\text{常數},\qquad \frac{dE_F}{dx}=0\quad\text{（熱平衡）}.$$

教材 §3.5 以兩側同一能量的電子交換率相等，得到兩側的費米占據機率相同，進而 $E_{F1}=E_{F2}$。這並**不**要求 $E_c(x)$ 或 $E_v(x)$ 水平；在接觸區它們通常彎曲。

## 2. 能帶彎曲與電場

在均勻材料、固定能隙且用電子能量作縱軸時，帶邊隨靜電位 $\phi$ 變化：$E_c(x)=E_{c,\mathrm{ref}}-q\phi(x)$，所以

$$\mathcal E_x=-\frac{d\phi}{dx}=\frac1q\frac{dE_c}{dx}.$$

此式只有在材料組成及帶邊參照不隨位置額外變動時可直接使用；異質接面有材料本身的帶邊階躍，不能把階躍全解釋成電場。

## 3. 考題畫圖順序

1. 指出材料、摻雜與接觸前的多數載子。
2. 若題目明說**熱平衡**，先畫一條水平 $E_F$。
3. 再畫符合材料能隙及接觸條件的 $E_c,E_v$；有內建電場時帶邊可彎曲。
4. 用[費米分布與濃度](/solid-state/chapter3/0003-carrier-concentrations)判斷哪裡電子或電洞較多。

若受光、外加偏壓等造成**非平衡**，電子與電洞可能需要各自的準費米能階；本頁的單一水平 $E_F$ 規則不能直接套用。

::: details 自我檢核：熱平衡接面上，$E_c$ 向右上升而 $E_F$ 水平，是否矛盾？
不矛盾。$E_F$ 固定代表無淨交換驅動；$E_c$ 的斜率可代表內建電場。兩者描述不同量。
:::
