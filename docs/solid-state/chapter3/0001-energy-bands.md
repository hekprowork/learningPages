# 0001：鍵結、能帶與直接／間接能隙

> 教材 Chapter 3，§3.1（PDF 閱讀頁 84–95）。先分清「能量對位置」與「能量對波向量」兩種圖。

## 1. 從原子能階到固體能帶

鍵結可用三種極端模型區分：NaCl 以電子轉移後正負離子的靜電吸引為主；金屬以離域電子與離子核心的作用為主；矽的四個價電子與四個最近鄰形成共價鍵。GaAs 的鍵結兼有共價與離子特性，不能只放進單一純粹類型。

大量原子靠近時，原本相同的原子能階因波函數重疊及不相容原理分裂成密集的**允許能帶**。在半導體，較低的價帶頂 $E_v$ 與較高的導帶底 $E_c$ 之間沒有允許的體材料電子態，間隔為

$$E_g=E_c-E_v.$$

熱或光可使價帶電子跨越能隙，留下電洞。金屬通常有部分填充能帶或重疊能帶；半導體與絕緣體在理想 $0\ \mathrm K$ 情形價帶滿、導帶空，兩者主要差在能隙尺度及可激發載子數，不能只用單一固定能隙界值分類。

## 2. 讀能帶圖先看橫軸

| 圖 | 橫軸 | 能回答的問題 |
| :--- | :--- | :--- |
| $E(x)$ | 空間位置 $x$ | 帶邊是否彎曲、不同材料接面、位能障壁 |
| $E(k)$ | 波向量 $k$ | 能帶極值、有效質量、直接或間接能隙 |

在 $E(x)$ 圖上，導帶電子的能量從 $E_c(x)$ 往**上**增加；價帶中的電洞能量從 $E_v(x)$ 往**下**增加。此處的 $E_c,E_v$ 是**電子能量**的帶邊，別把電洞的能量方向混為同一座標。

## 3. 直接與間接能隙

若導帶最低點與價帶最高點出現在相同 $k$，是**直接能隙**；否則是**間接能隙**。光子的動量相對晶體電子動量很小，因此直接能隙材料更容易以光子完成帶間輻射躍遷；間接躍遷通常需要聲子協助動量守恆。GaAs 是直接能隙，Si 是間接能隙。不要把「間接」誤認為不能吸光或絕對不能發光。

合金組成能改變能帶。教材 §3.1.5 的 $\mathrm{Al}_x\mathrm{Ga}_{1-x}\mathrm{As}$ 範例指出，隨 $x$ 改變，最低導帶谷可能切換，所以材料的直接／間接性也可能改變；合金不能只用兩端材料能隙的簡單線性平均判斷。

## 4. 考試判讀

題目若問光子能量門檻，先判 $E_g$；若問發光效率或聲子，先看極值是否同 $k$；若問接面、電場或障壁，先看 $E(x)$，不能由 $E(k)$ 的谷位置直接畫空間彎曲。

::: details 自我檢核：在 $E$–$k$ 圖中，導帶底與價帶頂能量差同為 $1.4\,\mathrm{eV}$，但兩者 $k$ 不同，這是何種能隙？
是**間接能隙**。$1.4\,\mathrm{eV}$ 只給能量差，還須查看波向量是否相同。
:::
